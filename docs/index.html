A FEW USEFUL DETAILS

Before you begin.

Which Macs are supported?
Transeen requires macOS 26 or later. One universal app supports Apple Silicon and Intel. The current app interface is in Simplified Chinese.
Can I use it offline?
After online activation and downloading Apple language packs, capture, annotation, and Apple translation work offline. Your cached license remains usable during temporary network failures; the app periodically revalidates it. External models require their configured connection.
Is the source really open?
Yes. The MIT license allows commercial use, modification, and redistribution. The official app requires a TR- code; the source license does not grant access to the hosted activation service.
What should I double-check?
Dense layouts, formulas, and specialist terminology can still need correction. Compare important details with the original, or open the text view for the complete translation.
How do I get updates?
Choose “检查更新…” in the menu bar or launcher. Transeen checks the latest GitHub release and opens the download page when a new version is available.
