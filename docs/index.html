Fig 1.0  How it works

One key, four steps. Transeen reads the pixels you select and sets your language back into them, without leaving the Mac.

  1. 1.1  Select

    Frame what you can’t read

    The screen holds still. Hover to snap to a paragraph, a field or a window, or drag a frame of your own.

  2. 1.2  Recognize

    Each line is read on your Mac

    Apple’s Vision framework finds every line and its style. Nothing is uploaded to do it.

  3. 1.3  Lift

    Only the ink comes off

    The letters are lifted out and the background underneath them is rebuilt, gradient or texture included.

  4. 1.4  Set

    Yours go where they were

    Same position, size and color. A line is narrowed or wrapped only when the translation would not fit.

Fig 2.0  Any app

Any app, and across apps. Transeen reads the pixels on your screen, so it works wherever text appears, with nothing to install in the app.

  • No plug-ins, no integrationsBrowsers, chat, PDFs, games, design tools, remote desktops: if it is on the screen, it can be translated. Even text you can’t select.
  • One frame across several appsA frame can cover windows from different apps at once. Every line inside it is translated in the same capture.
  • Over full-screen apps, on every SpaceF1 works in a full-screen app and on any desktop. An open menu, popover or tooltip stays in the picture, and the app keeps focus.
  • Snaps to what is thereHover and the frame finds the paragraph, field or window under the pointer, in whatever app it belongs to.
  • Pins float over every appA pinned translation stays above whatever you switch to, so you can read it next to the app you are working in.

Fig 4.0  The capture

A capture you can work with. It stays where you selected it, with the tools underneath.

  • Mark it up

    Boxes, ellipses, arrows, the pen and numbered notes, in six colors. Marks sit on their own layer, so switching languages never moves them.

  • Missed a line? Pull an edge

    Drag an edge or a corner. Transeen re-crops from the same frozen screen and translates again when you let go.

  • Pin it, keep capturing

    A pin floats on the screen as a picture of its own. Keep as many as you need; right-click one to copy, save or switch it.

  • Copy what you see

    ⌘C copies the picture with your marks, even while the translation is still arriving. ⌘S saves a PNG.

  • Read it as text

    Open the full translation beside the original as a list you can select and copy.

  • Open an image

    A screenshot someone sent you works too. Press ⌘O and it opens with the same tools.

Fig 5.0  Translation

Three ways to translate. Pick one in Settings, change it any time. Recognition always happens on your Mac.

  • Apple Translation Default

    The translation built into macOS. Download a language pack once and it works offline.

    • RunsOn this Mac
    • DownloadPer language pack
    • SpeedIn groups of 8 lines

  • Local Translation Model Apple silicon

    Index-Translate 2B or Hy-MT2 1.8B, run by Transeen itself. Better with developer text and interface labels.

    • RunsOn this Mac
    • DownloadAbout 1.1 GB, checked
    • MemoryFreed after 5 idle minutes

  • LLM API Your endpoint

    Any OpenAI-compatible chat/completions endpoint, remote over HTTPS or a server on localhost.

    • SendsRecognized text only
    • KeyKept in your Keychain
    • AnswersShown as they arrive

The screenshot never leaves your Mac. Transeen keeps no capture history and never records continuously. With Apple Translation or a local model, the text stays on the Mac too.

Fig 7.0  Changelog

Recently shipped. Small releases, often. The full list is on GitHub.

0.11.2Oct 31, 2026

  • Pictures stay pictures. A row of thumbnails next to the text is no longer read as words and covered with a translation. A line the recognizer is unsure of is read again, magnified, and kept only if it reads the same.
  • Chinese inside English is kept. A Chinese word in an English sentence stays Chinese instead of turning into Latin letters.
  • Drawing tools always draw. An arrow started on a number or a box no longer picks that mark up. The capture stays where it was taken; only a pin moves with the mouse.

0.11.1Oct 30, 2026

  • Every sentence is translated. A long paragraph a local model was slow on is sent again on its own, instead of keeping its original.
  • The screen freezes first. F1 keeps another app’s open menu, popover or tooltip in the picture, and that app keeps focus.
  • Cleaner erasing. Letters like g and y no longer leave marks, and a floating arrow no longer turns into stray characters.

Fig 9.0  Questions

Questions. Anything else, ask in GitHub Discussions.

Which apps does it work with?

Any app that shows text on the screen: browsers, chat and mail, PDF readers, games, design and video tools, remote desktops and virtual machines. Transeen translates the pixels you select, so it needs no plug-in or support from the app, and one frame can take in windows from several apps. Video that an app protects from screen recording comes out black, as it does in any screenshot.

Which Macs does Transeen run on?

macOS 26 or later, on Apple silicon or Intel: it is one universal app. The local translation models need Apple silicon. The interface follows your language: English, 简体中文, 繁體中文, 日本語, 한국어, Français, Español or Deutsch.

Does it work offline?

Yes, once it is activated. Capture, annotation, Apple Translation and the local models work offline after their language packs or model are downloaded. An activation stays valid through network outages and is checked again about once a day. An LLM API needs a connection to your endpoint.

What leaves my Mac?

With Apple Translation or a local model, nothing: the screenshot, the recognized text and the translation stay on this Mac. With an LLM API only the recognized text goes to the endpoint you set, never the screenshot. Activation sends your code and a random installation ID, and update checks contact GitHub.

Can I use a different model?

Yes. In Settings → General → Translation, download Index-Translate 2B or Hy-MT2 1.8B (about 1.1 GB each), which run inside Transeen, or enter any OpenAI-compatible chat/completions endpoint, a model name and, if it needs one, a key kept in your Keychain. Remote endpoints must use HTTPS; a server on localhost can use HTTP without a key.

Can it translate an image I already have?

Yes. Choose Open Image… in the launcher or press ⌘O; the picture opens in the same window, with the same tools.

How accurate is it?

That depends on the translation service. Dense layouts, formulas and specialist terms can need correcting, so compare with the original using Tab, or open the full text, before you rely on a detail.

Is Transeen open source?

Yes, under the MIT license, commercial use included. The official app needs a TR- code; the source license does not include the hosted activation service, so independent builds bring their own.

How do I update?

Choose Check for Updates… in the menu bar or the launcher. Transeen checks GitHub Releases and opens the download when a newer version exists.
