Fig 2.0  모든 앱

어떤 앱에서든, 여러 앱에 걸쳐서도. 화면의 픽셀을 읽기 때문에 앱에 설치할 것이 없습니다.

  • 플러그인 불필요브라우저, 채팅, PDF, 게임, 원격 데스크톱. 선택할 수 없는 글자도.
  • 여러 앱을 한 번에서로 다른 앱의 창을 캡처 한 장에 담습니다.
  • 전체 화면에서도열린 메뉴와 툴팁도 그림에 남습니다.
  • 고정한 그림은 맨 위에어떤 앱으로 전환해도 번역이 곁에 있습니다.

Fig 4.0  캡처

찍은 뒤에도 바로 쓰는 캡처. 도구는 바로 아래에.

  • 주석

    사각형, 화살표, 펜, 번호를 별도 레이어에.

  • 가장자리 끌기

    한 줄을 놓쳤다면 가장자리를 끌어 다시 번역.

  • 고정

    화면에 띄워 두고 계속 캡처.

  • 복사

    ⌘C로 주석까지 복사.

  • 텍스트로 읽기

    전체 번역을 바로 복사.

  • 이미지 열기

    ⌘O로 갖고 있는 스크린샷도.

Fig 5.0  번역

번역하는 방법은 세 가지. 인식은 언제나 Mac에서.

  • Apple 번역 기본값

    macOS 내장. 언어 팩을 받으면 오프라인으로.

  • 로컬 모델 Apple 실리콘

    Index-Translate 또는 Hy-MT2를 Transeen이 직접 실행.

  • LLM API 원하는 주소

    OpenAI 호환 API. 텍스트만 보냅니다.

스크린샷은 Mac 밖으로 나가지 않습니다. 기록도, 연속 녹화도 없습니다.

Fig 9.0  자주 묻는 질문

자주 묻는 질문.

어떤 앱에서 쓸 수 있나요?

화면에 글자를 보여 주는 앱이라면 모두 됩니다. 선택한 영역의 픽셀을 번역하므로 플러그인이 필요 없고, 영역 하나로 여러 앱을 감쌀 수 있습니다. 화면 기록이 막힌 동영상은 다른 스크린샷과 마찬가지로 검게 나옵니다.

어떤 Mac에서 작동하나요?

macOS 26 이상, Apple 실리콘과 Intel 모두에서 작동합니다. 로컬 모델에는 Apple 실리콘이 필요합니다.

오프라인에서도 되나요?

네. 활성화하고 언어 팩이나 모델을 내려받으면 됩니다. LLM API만 네트워크가 필요합니다.

Mac 밖으로 무엇이 나가나요?

Apple 번역이나 로컬 모델이라면 아무것도 나가지 않습니다. LLM API는 인식한 텍스트만 엔드포인트로 보내고, 스크린샷은 보내지 않습니다.

다른 모델을 쓸 수 있나요?

네. 설정에서 Index-Translate 2B나 Hy-MT2 1.8B를 내려받거나, OpenAI 호환 API를 입력하세요. 키는 키체인에 보관됩니다.

이미 가진 이미지도 번역되나요?

네. ⌘O로 열면 같은 도구를 쓸 수 있습니다.

얼마나 정확한가요?

번역 서비스에 따라 다릅니다. 세부 내용을 믿기 전에 Tab으로 원문을 확인하세요.

Transeen은 오픈 소스인가요?

네, MIT 라이선스입니다. 공식 앱에는 TR- 코드가 필요합니다.

업데이트는 어떻게 하나요?

메뉴 막대에서 ‘업데이트 확인…’을 고르세요.

F1

있는 그 자리에서 읽으세요.

F1을 눌러, 처음 읽지 못했던 곳을 선택해 보세요.
