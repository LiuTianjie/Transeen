Transeen/설정 가이드

다섯 단계로 Transeen 준비하기.

다운로드부터 첫 스크린샷 번역까지. macOS 26 이상의 Mac과 TR- 활성화 코드가 필요합니다.

01설치

  1. GitHub Releases에서 최신 DMG를 내려받습니다. 약 10MB이며, Apple 실리콘과 Intel을 모두 지원하는 유니버설 앱입니다.
  2. DMG를 열고 Transeen을 응용 프로그램 폴더로 끌어 놓습니다.
  3. 응용 프로그램 폴더에서 Transeen을 엽니다. 메뉴 막대에서 실행되므로 Dock이 아닌 메뉴 막대에서 아이콘을 찾으세요.

앱과 DMG는 Developer ID로 서명하고 Apple의 공증을 받았기 때문에 macOS가 경고 없이 엽니다. 같은 릴리스 페이지에 ZIP과 SHA-256 체크섬도 있습니다. 인터페이스는 Mac의 언어를 따릅니다: English, 简体中文, 繁體中文, 日本語, 한국어, Français, Español, Deutsch.

02활성화

  1. 메뉴 막대 메뉴에서 활성화 및 계정…을, 또는 홈 창에서 Transeen 활성화를 고릅니다.
  2. TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX 형식의 코드를 입력하고 이 Mac 활성화를 고릅니다. 로그인은 필요 없습니다.
  3. 원하면 Google, GitHub, 이메일로 iTool 계정에 로그인해 라이선스를 연결합니다. 나중에 같은 계정으로 로그인하면 복원됩니다.

활성화는 무작위 설치 ID와 영수증만 키체인에 저장하고, Mac의 일련번호는 읽지 않습니다. 코드 하나는 Mac 한 대용이며, 계정을 연결해도 라이선스가 늘어나지 않습니다. StupidMirror의 SM- 코드와 iTool Pro의 IT- 코드는 다른 제품이라 여기서는 쓸 수 없습니다. 코드가 필요하면 GitHub Discussions에 문의하세요.

03화면 기록 허용

처음 캡처할 때 Transeen이 화면 기록 권한을 요청합니다. 오디오는 쓰지 않고 화면 이미지만, 그것도 캡처 단축키를 누를 때만 사용합니다. 기록을 남기지 않고 계속 녹화하지도 않습니다.

  1. 시스템 설정 열기…를 고르거나 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록으로 갑니다.
  2. Transeen을 찾아 켭니다.
  3. Transeen으로 돌아옵니다. 자동으로 다시 확인해 준비 완료가 표시되면 영역 선택으로 계속합니다.

켜 두었는데도 작동하지 않으면 같은 창에서 다시 확인이나 다시 열기를 누르세요.

04언어 선택

홈 창에는 원문 언어와 번역 언어 두 메뉴가 있습니다. 원문은 자동 감지로 두거나 여덟 가지 언어 중 하나를 고르세요: 중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 프랑스어, 스페인어, 독일어. 어느 언어에서 다른 어느 언어로든 번역합니다.

캡처가 열려 있을 때는 도구 아래의 방향(예: JA → KO)에서 어느 쪽 언어든 바꿀 수 있고, F1을 한 번 더 누르면 두 언어가 바뀝니다.

Apple 번역은 언어 조합마다 언어 팩이 필요합니다. 처음 실행할 때 열리는 안내와 이후의 설정 → 일반 → 번역에서 번역 언어에 필요한 팩과 상태를 보여 줍니다. 다운로드로 미리 받아 두면 첫 캡처에서 기다리지 않고, 이후 번역은 Mac에서 오프라인으로 이루어집니다. 언어 팩은 시스템 설정 → 일반 → 언어 및 지역 → 번역 언어에서도 볼 수 있습니다.

05영역 번역

  1. 어떤 앱에서든 F1을 누릅니다. 화면이 멈추고 어두워집니다. 노트북 키보드에서는 fn F1입니다(F 키를 표준 기능 키로 쓰도록 설정한 경우는 제외).
  2. 포인터를 올려 문단, 입력란, 창에 맞춘 뒤 클릭하거나, 직접 영역을 끕니다. 영역은 여러 앱의 창에 걸쳐도 됩니다. Esc나 오른쪽 클릭으로 취소합니다.
  3. 지난번과 같은 자리라면, 선택하는 동안 R을 눌러 지난 캡처의 영역을 다시 씁니다. 재시동 후에도 됩니다.
  4. 번역은 원래 글자가 있던 자리에 나타나고, 번역되는 대로 한 줄씩 표시됩니다. Tab으로 원문과 번역을 오가고, 스페이스를 누르고 있으면 원문을 엿볼 수 있습니다.
  5. 조금 모자라면 캡처의 가장자리나 모서리를 끕니다. 같은 정지 화면에서 다시 잘라내고 주석은 그대로 둔 채, 손을 떼면 다시 번역합니다.
  6. 방향이 반대라면 캡처가 열린 상태에서 F1을 한 번 더 눌러 두 언어를 바꿉니다.

Transeen은 화면의 픽셀을 읽으므로 전체 화면 앱과 모든 Space를 포함해 어떤 앱에서든 똑같이 작동하고, 열려 있는 메뉴나 툴팁도 그림에 남습니다. 처음부터 어떤 앱에서든 쓸 수 있는 단축키는 F1뿐입니다. 번역 없이 주석만 달려면 메뉴 막대 메뉴에서 주석을 고르거나 설정 → 단축키에서 키를 지정하세요. 그 창에서 T를 누르면 나중에 번역할 수도 있습니다. 갖고 있는 이미지를 번역하려면 이미지 열기…를 고르거나 ⌘O를 누릅니다.

06주석 달기

도구 막대에서 도구를 고르거나 키를 누릅니다: R 사각형, O 타원, A 화살표, P 펜, V 선택 및 이동. 그리기 도구는 기존 주석 위에서 시작해도 언제나 그립니다. 주석을 집으려면 V를 쓰세요. 번호는 1부터 올라가며 실행 취소와 다시 실행 후에도 그대로입니다.

여섯 가지 색과 세 가지 굵기 중에서 고르거나, 슬라이더로 원하는 색과 1에서 10까지의 굵기를 고를 수 있습니다. ⌘Z와 ⌘⇧Z로 실행 취소와 다시 실행, Delete로 선택한 주석을 지웁니다. 주석은 별도 레이어에 있어 원문과 번역을 바꿔도 움직이지 않습니다.

07복사, 저장, 고정

  • ⌘C는 주석을 포함해 보이는 그대로 그림을 복사합니다. 번역이 진행 중이어도 됩니다. 기본적으로 복사하면 캡처도 닫힙니다. 열어 두려면 설정에서 복사 후 캡처 닫기를 끄세요.
  • ⌘S는 PNG로 저장합니다.
  • 화면에 고정은 그림을 독립된 떠 있는 창으로 화면에 남기고 캡처를 끝내므로, 바로 다음 캡처를 시작할 수 있습니다. 고정한 그림은 전환한 앱 위에 머무릅니다. 어디로든 끌어 놓고 필요한 만큼 둘 수 있으며, 오른쪽 클릭으로 복사, 저장, 원문과 번역 전환, 닫기를 할 수 있습니다.
  • 텍스트는 전체 번역을 원문 옆에 열어 바로 복사할 수 있게 합니다.

08번역 서비스 고르기

설정(⌘,) → 일반 → 번역에서 번역 서비스를 고릅니다. 글자 인식은 항상 Mac에서 합니다.

Apple 번역(기기 내)

기본값입니다. 4단계의 언어 팩을 쓰고, 오프라인으로 작동하며, 어디에도 아무것도 보내지 않습니다. 8줄씩 번역하므로 긴 캡처도 읽는 동안 채워집니다.

로컬 번역 모델

Index-Translate 2B 또는 Hy-MT2 1.8B(각각 약 1.1GB)를 내려받습니다. 모델은 Transeen 안에서 실행되며 계정도, 추가 앱도, 네트워크도 필요 없습니다. Apple 실리콘 Mac이 필요합니다. 첫 번역은 모델을 불러오느라 몇 초 걸리고, 5분 동안 쓰지 않으면 메모리를 해제합니다. 모델 삭제로 다시 지울 수 있습니다.

LLM API

OpenAI 호환 chat/completions 엔드포인트라면 무엇이든 됩니다. 다음을 입력합니다:

  • 엔드포인트: 전체 URL. 예: https://api.openai.com/v1/chat/completions
  • 모델 이름
  • 서비스에 필요하면 API 키를 입력하고 키 저장. 키는 키체인에 보관됩니다. 연결 테스트로 확인할 수 있습니다.

내 Mac에서 돌리는 서버도 됩니다. 로컬 주소는 일반 HTTP를 써도 되고 키도 필요 없습니다. 예를 들어 Ollama는 http://localhost:11434/v1/chat/completions입니다. 원격 주소는 HTTPS여야 합니다. 이 방식은 인식한 텍스트만 보내고 스크린샷은 보내지 않습니다. 요청이 실패하면 Transeen이 오류를 보여 주고 원래 그림을 그대로 둡니다.

10문제 해결

F1을 눌러도 아무 일도 없어요

노트북 키보드에서는 fn을 누르지 않으면 F1이 밝기를 조절합니다. 또는 시스템 설정 → 키보드 → 키보드 단축키 → 기능 키에서 ‘F1, F2 등의 키를 표준 기능 키로 사용’을 켜세요. 다른 앱이 F1을 쓰고 있을 수도 있으며, 단축키를 등록할 수 없으면 Transeen이 알려 줍니다. 설정 → 단축키에서 다른 키를 고르거나 메뉴 막대 메뉴의 캡처 후 번역으로 시작하세요.

캡처가 비어 있거나 권한을 계속 묻습니다

메뉴 막대 메뉴에서 화면 권한…을 엽니다. 시스템 설정에 Transeen이 이미 켜져 있다면 껐다가 다시 켠 뒤 다시 열기를 고르세요.

창의 일부가 검게 나옵니다

동영상 같은 콘텐츠를 화면 기록으로부터 보호하는 앱이 있으며, 그 부분은 어떤 스크린샷에서도 검게 찍힙니다. Transeen도 그 부분은 읽거나 번역할 수 없지만, 영역 안의 나머지는 평소처럼 번역합니다.

Apple 번역이 시작되지 않아요

그 언어 조합의 언어 팩이 없거나 아직 내려받는 중일 수 있습니다. 설정 → 일반 → 번역에서 내려받거나 시스템 설정 → 일반 → 언어 및 지역 → 번역 언어를 확인한 뒤 다시 시도하세요.

로컬 모델이 시작되지 않아요

한 번 다시 시도하세요. 그래도 안 되면 설정 → 일반 → 번역에서 모델을 삭제하고 다시 내려받습니다. 체크섬 검증에 실패한 다운로드는 자동으로 삭제됩니다.

일부 글자가 잘못 번역돼요

빽빽한 레이아웃, 수식, 전문 용어는 인식이나 번역을 틀리게 할 수 있습니다. 원문과 비교하거나(Tab), 텍스트로 전체 번역을 열거나, 더 작은 영역을 선택해 보세요.

11소스에서 빌드

Transeen은 MIT 라이선스입니다. Xcode 26.4 이상, Swift 6, XcodeGen이 필요합니다.

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

앱은 dist/Transeen.app에 만들어집니다. Developer ID가 없으면 애드혹 서명으로 빌드되며, 서명된 빌드를 원하면 TRANSEEN_SIGNING_IDENTITY를 설정하세요. 테스트는 ./scripts/test.sh, ./scripts/test-license.sh, ./scripts/test-lifecycle.sh입니다. 호스팅 활성화 서비스는 공식 앱의 것이므로, 독립적으로 배포하려면 자체 라이선스 백엔드가 필요합니다.
