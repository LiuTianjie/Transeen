Fig 1.0  So funktioniert’s

Eine Taste, vier Schritte. Alles auf deinem Mac.

  1. 1.1  Auswählen

    Einrahmen

    Der Bildschirm hält still. Rasten oder selbst einen Rahmen ziehen.

  2. 1.2  Erkennen

    Auf dem Mac gelesen

    Apple Vision findet jede Zeile. Nichts wird hochgeladen.

  3. 1.3  Abheben

    Die Schrift geht ab

    Die Buchstaben gehen ab, der Hintergrund wird ergänzt.

  4. 1.4  Setzen

    Zurück an ihren Platz

    Gleicher Ort, gleiche Größe und Farbe, in deiner Sprache.

Fig 4.0  Die Aufnahme

Eine Aufnahme zum Weiterarbeiten. Die Werkzeuge direkt darunter.

  • Markieren

    Rahmen, Pfeile, Stift und Nummern, auf eigener Ebene.

  • Am Rand ziehen

    Zeile vergessen? Rand ziehen, und es wird neu übersetzt.

  • Anheften

    Auf dem Bildschirm lassen und weiter aufnehmen.

  • Kopieren

    ⌘C kopiert, was du siehst, mit Markierungen.

  • Als Text lesen

    Die ganze Übersetzung, bereit zum Kopieren.

  • Bild öffnen

    ⌘O für Screenshots, die du schon hast.

Fig 5.0  Übersetzung

Drei Wege zu übersetzen. Die Erkennung bleibt immer auf deinem Mac.

  • Apple-Übersetzung Standard

    In macOS eingebaut. Offline, sobald das Sprachpaket da ist.

  • Lokales Modell Apple-Chip

    Index-Translate oder Hy-MT2, von Transeen selbst ausgeführt.

  • LLM-API Dein Endpunkt

    Jede OpenAI-kompatible API. Gesendet wird nur der Text.

Der Screenshot verlässt nie deinen Mac. Kein Verlauf, keine Daueraufnahme.

Fig 9.0  Fragen

Fragen.

Mit welchen Apps funktioniert es?

Mit jeder App, die Text auf dem Bildschirm zeigt. Transeen übersetzt die ausgewählten Pixel, braucht also kein Plug-in, und ein Rahmen kann mehrere Apps umfassen. Video, das vor Bildschirmaufnahmen geschützt ist, erscheint schwarz, wie in jedem Screenshot.

Auf welchen Macs läuft es?

macOS 26 oder neuer, auf Apple-Chip oder Intel. Die lokalen Modelle brauchen einen Apple-Chip.

Funktioniert es offline?

Ja, sobald es aktiviert ist und das Sprachpaket oder Modell geladen ist. Nur eine LLM-API braucht eine Verbindung.

Was verlässt meinen Mac?

Mit der Apple-Übersetzung oder einem lokalen Modell nichts. Mit einer LLM-API geht nur der erkannte Text an deinen Endpunkt, nie der Screenshot.

Kann ich ein anderes Modell nutzen?

Ja: Lade Index-Translate 2B oder Hy-MT2 1.8B in den Einstellungen oder gib eine OpenAI-kompatible API ein. Schlüssel bleiben im Schlüsselbund.

Kann es ein vorhandenes Bild übersetzen?

Ja. Drück ⌘O, und es öffnet sich mit denselben Werkzeugen.

Wie genau ist es?

Das hängt vom Übersetzungsdienst ab. Prüf mit Tab das Original, bevor du dich auf ein Detail verlässt.

Ist Transeen Open Source?

Ja, unter der MIT-Lizenz. Die offizielle App braucht einen TR-Code.

Wie aktualisiere ich?

Wähl in der Menüleiste „Nach Updates suchen…“.
