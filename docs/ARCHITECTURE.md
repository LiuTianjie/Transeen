# Transeen 第一版架构

2026-10-03。先明确交互与边界，再实现。

## 产品与交互

独立 macOS 26+ 菜单栏截图应用，不依赖输入法、语音模型或 Saylane 进程。

- 默认全局快捷键只有 F1：截图翻译。截图标注和全局对照原文默认不设快捷键，都可在设置里修改。快捷键存于 `keyboardShortcuts.v2`，早期版本保存的快捷键不沿用。
- 框选时按 R（「框选」分组）选择上次截图的区域，跨重启保留；同一按键在截图窗口里仍是矩形工具。快捷键只在能同时生效的分组之间判定冲突。
- 首次启动显示新手引导：激活、屏幕录制权限、翻译语言与 Apple 语言包下载、快捷键。语言包用 LanguageAvailability 查询，由引导或设置窗口自己的 `.translationTask` 只做 `prepareTranslation` 下载，截图时不再临时弹出下载。
- 框选沿用窗口/内容吸附与自由拖拽，背景冻结在捕获帧上。选中后从同一帧裁剪，在原坐标展示。跨越显示器边缘时裁剪到起始显示器，避免拉伸。
- 结果出现后，拖动边或角从同一冻结帧重新裁剪（限于起始显示器，按像素对齐），标注与撤销历史随原点平移；进行中的翻译作废，松手后在译文视图下重新翻译。复制不等待翻译，复制当前所见画面。
- 行内代码块（chip）所在的句子整句翻译：同一识别行的样式片段合回一行，chip 以 `literal` 的形式进入原文，跨行照常合段。译文按 chip 文字（或译者加的引号）找回每个 chip，排版时 chip 作为不可断开的原像素块与文字一起换行，原位置用纸色擦除（擦除范围是与 chip 文字相连的非纸色区域，含边框）。找不回全部 chip 时整句保留原图。
- 拖动期间窗口扩展到整块冻结帧并保持不动，冻结帧作为一个图层只移动裁剪位置，工具栏只跟随不重新测量；松手才按像素裁剪一次。逐次裁剪重绘和工具栏的动画改尺寸（同步阻塞约 0.2 秒）是此前卡顿的原因。
- 结果打开时再按截图翻译快捷键：未翻译过则翻译，否则交换原文与译文语言；Esc 关闭。
- 钉住把当前所见画面（含标注，译图时附带原图）交给独立的 PinnedImagePanel，随即结束本次截图，因此不妨碍继续截图。钉图可拖动，右键菜单提供复制、保存、切换原文/译文和关闭，聚焦时 Esc 关闭。
- 截图窗口停在截取的位置，拖动图片不会移动窗口，只有钉图跟随鼠标。绘图工具（矩形、椭圆、箭头、画笔）按下即画，即使落在已有标注上也不会选中它、切回指针；只有选中标注的控制点可以直接调整。编号工具按在已有编号上会移动它。选中绘图工具时图片边缘也用于绘制，调整范围只从图片外侧的边距开始。
- 截图模式不运行 OCR，也不发送模型请求；点击翻译或 T 后才开始。
- Tab 切换原文/译文（全局对照原文需自行设置快捷键）；画笔、矩形、椭圆、箭头和编号在独立标注层，切换不丢失。
- ⌘Z/⌘⇧Z 撤销/重做；⌘C 复制当前图层合成；⌘S 保存 PNG；Esc 关闭。

## 模块

App（菜单栏、快捷键、设置、权限） → CaptureController（会话与取消） → ScreenCaptureKit → ScreenPipeline（Vision OCR、像素样式测量、分块、排版、笔画擦除、合成） → CapturePanel（原图/译图 + AnnotationCanvas + 独立工具栏）。

三层数据：原始截图不可变；译图与原图同尺寸；标注使用点坐标，导出按原像素比例绘制。禁止把标注送去 OCR 或翻译。没有截图历史和默认自动上传。

流水线从 rtranslate fe5c74a59afb359003e1da967f831450017890f3 抽取，以源码快照独立维护；不改原项目。保留现有取色、字号、背景擦除和排版实现。精翻的结构化输出解析与校验同样复用。

## 翻译后端

Apple Translation 是默认后端；首次需下载系统语言包，下载后本机运行。独立的 TranslationBackend 协议允许替换翻译实现。

原文语言可自动识别，也可明确指定。OCR 后按文字语言判断保留或翻译，日文、韩文不会被合并当作中文跳过；等宽字体只作为排版样式，是否为代码由内容判断。模型批次在原截止时间内最多补试一次缺失条目，TranslationOutput 同时携带有效译文、明确保留的条目和部分失败提示。

Apple 下载宿主中的 `.translationTask` 会话只用于 `prepareTranslation`，绝不储存到引擎。翻译使用独立的 `installedSource` 会话，每批工作完成或取消后销毁。macOS 26.4 起显式区分 high-fidelity 与 low-latency 资产，优先已就绪的高质量模型，否则使用普通离线语言包。

本地模型模式（`LocalModelTranslationBackend`）运行用户下载的 GGUF 翻译模型。目录在 `LocalModelCatalog`：Index-Translate 2B Q3_K_M 与 Hy-MT2 1.8B Q4_K_M，各约 1.1 GB，Apache-2.0。`LocalModelStore` 把模型存到 `~/Library/Application Support/Transeen/Models`：中国大陆先用 ModelScope、其他地区先用 Hugging Face，失败换另一个源；`.partial` 文件用 Range 续传，写入时同步计算 SHA-256，与目录中的值不符即删除。`LocalModelRuntime` 启动 `Contents/Helpers/llama-server`（`scripts/build-llama.sh` 从固定的 llama.cpp 提交编译：静态 arm64、内嵌 Metal 着色器、无 Web UI，约 16 MB，与主程序同一 Developer ID 和 hardened runtime 签名），只监听 127.0.0.1 的随机端口，并使用每次启动随机生成的 API key。服务器由一个 `/bin/sh` 看护进程托管，Transeen 退出或崩溃一秒内随之结束。截图选区时预先加载模型，空闲 5 分钟后停止以释放约 1.8 GB 内存。每个文字块一次请求，4 路并行，使用各模型训练时的单条 user 提示词，反引号代码块原样保留。

模型模式使用完整 OpenAI 兼容 chat/completions URL、模型名和 Keychain 密钥。远端只允许 HTTPS，本机回环地址允许 HTTP、可无密钥。只发送识别后的结构化文本，不发送截图。支持本机已运行的兼容服务（如 LM Studio、Ollama）。模型失败展示错误并保留原图，Apple 与模型可独立使用。

## 会话与取消

框选后从冻结画面裁剪，一次翻译对应一次截图；不持续捕获屏幕。generation 校验阻止关闭、重选或切换语言方向后的旧任务回写。捕获过滤排除本进程所有窗口。

工具栏一行包含对照、形状、编号和输出操作；选中标注工具后第二行显示颜色、笔触与撤销重做。自定义颜色、粗细和编号大小通过调节图标打开。编号从 1 递增，撤销重做保留数字；新截图重新计数。

## 验证与边界

构建、1x/2x 流水线回归、结构化模型输出校验、标注导出、会话取消分别验证。真实录屏权限、全局快捷键、多屏幕与全屏窗口和实际模型服务单列实机验收，构建通过不视为这些行为已经通过。

## 权限与原生交互

权限流程由 ScreenPermission 持有状态与待继续的捕获模式，PermissionGuide 使用系统按钮和原生 NSButton 对照样例。窗口恢复激活与可见期间定时刷新授权状态；点击继续才恢复框选。UI 方向见 docs/design/INTERACTION.md。

## 实机回归修正

密集原生文本的 OCR 行框可能跨入下一行，原像素测量把两行笔画一起当成一行，导致 12pt 文本被估成约 28pt。ScreenPipeline 现在根据横向重叠的相邻识别行中点限定测量范围；InkAnalyzer 仍只擦除本行笔画。真实样本位于 Tests/Fixtures/dense-native-text.png。

构建产物和 dist 应用使用同一 Developer ID Application 身份签名，避免临时 cdhash 随重建变化造成 TCC 授权失效。
