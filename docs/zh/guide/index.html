Transeen/使用指南

五步装好 Transeen，然后按 F1。

从下载到第一次截图翻译。你需要一台 macOS 26 或更高版本的 Mac，和一个 TR- 激活码。

01安装

  1. 从 GitHub Releases 下载最新的 DMG。大约 10 MB，一个通用版本同时支持 Apple 芯片和 Intel。
  2. 打开 DMG，把 Transeen 拖进“应用程序”。
  3. 从“应用程序”打开 Transeen。它常驻在菜单栏，不在程序坞里，请在菜单栏找它的图标。

应用和 DMG 都用 Developer ID 签名并经过 Apple 公证，macOS 打开时不会弹出警告。同一个发布页还有 ZIP 和 SHA-256 校验值。界面语言跟随系统：简体中文、繁體中文、English、日本語、한국어、Français、Español、Deutsch。

02激活

  1. 在菜单栏菜单中选择 激活与账号…，或在主窗口中选择 激活 Transeen。
  2. 输入激活码，格式是 TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX，然后选择 激活这台 Mac。无需登录。
  3. 如果愿意，可以用 Google、GitHub 或邮箱登录 iTool 账号并绑定授权。以后登录同一账号即可恢复。

激活只在钥匙串里保存一个随机安装 ID 和一份凭证，不读取 Mac 的序列号。一个激活码对应一台 Mac，绑定账号不会多出一份授权。StupidMirror 的 SM- 和 iTool Pro 的 IT- 激活码属于其他产品，在这里不能用。想要激活码，请在 GitHub Discussions 留言。

03开启屏幕录制

第一次截图时，Transeen 会请求屏幕录制权限。它只用屏幕画面，不录音，而且只在你按下截图快捷键时才截取。它不保存历史，也从不持续录屏。

  1. 选择 打开系统设置…，或前往系统设置 → 隐私与安全性 → 屏幕与系统音频录制。
  2. 找到 Transeen 并打开开关。
  3. 回到 Transeen。它会自动重新检查并显示 已准备好，选择 开始框选 继续。

如果开关已打开但仍不生效，在同一个窗口里点 重新检查 或 重新打开。

04选择语言

主窗口有两个菜单：原文语言 和 译文语言。原文可以保持 自动识别，也可以从八种语言中选一种：简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、德语。任意两种之间都能互译。

截图打开时，工具下方的方向（例如 JA → ZH）可以改任一边的语言；再按一次 F1 就交换两边。

Apple 翻译每一对语言都需要语言包。首次启动的引导，以及之后的设置 → 通用 → 翻译，会列出目标语言需要的语言包和状态。点 下载 提前装好，第一次截图就不用等；之后翻译完全在本机离线完成。语言包也可以在系统设置 → 通用 → 语言与地区 → 翻译语言中查看。

05框选翻译

  1. 在任意软件里按 F1。屏幕会定格并变暗。在笔记本键盘上是 fn F1，除非你把 F 键设成了标准功能键。
  2. 移动指针会自动吸附到段落、输入框或窗口，点一下即可；也可以自己拖一个框，一个框可以跨过几个软件的窗口。Esc 或右键取消。
  3. 和上次同一个位置？框选时按 R，直接沿用上一次截图的区域，重启后也有效。
  4. 译文出现在原文所在的位置，逐行翻好逐行显示。按 Tab 在原文和译文之间切换，按住 空格 临时看原文。
  5. 少框了一点？拖动截图的边或角。它会从同一张定格画面重新裁切，标注留在原处，松手后重新翻译。
  6. 方向反了？截图打开时再按一次 F1，两种语言会对调。

Transeen 读的是屏幕像素，所以在每个软件里用法都一样，全屏软件和每个桌面也包括在内，打开着的菜单或提示也会留在画面里。F1 是默认唯一在任何软件里都能用的快捷键。只想截图标注、不翻译，可以在菜单栏菜单中选择 截图标注，或在设置 → 快捷键中给它分配一个键；在那个窗口里按 T 仍可翻译。要翻译已有的图片，选择 打开图片… 或按 ⌘O。

06标注

在工具栏选工具，或直接按键：R 矩形、O 椭圆、A 箭头、P 画笔、V 选择和移动。绘图工具按下就画，从已有的标注上起笔也一样；要拿起某个标注，用 V。序号标注从 1 开始递增，撤销和重做后编号不变。

有六种颜色和三种粗细可选，也可以打开滑块选任意颜色和 1 到 10 的线宽。⌘Z 和 ⌘⇧Z 撤销、重做，Delete 删除选中的标注。标注在单独的图层上，切换原文和译文时不会移动。

07复制、保存或钉图

  • ⌘C 按你看到的样子复制图片，包括标注，即使译文还在生成也可以。默认复制后会关闭截图；在设置中关掉 复制后关闭截图 即可保留。
  • ⌘S 存成 PNG。
  • 钉到屏幕 把图片留在屏幕上，成为一个独立的浮动窗口，同时结束本次截图，马上可以截下一张。钉图会停在你切换到的软件上方，可以拖到任何地方，想留几张都行；右键可复制、保存、切换原文和译文或关闭。
  • 文字 打开完整译文，与原文并排，方便复制。

08选择翻译服务

打开设置（⌘,）→ 通用 → 翻译，选择 翻译服务。文字识别始终在本机完成。

Apple 本机翻译

默认选项。使用第 4 步的语言包，离线运行，不向任何地方发送内容。文字每 8 行一组翻译，长截图会边看边填满。

本地翻译模型

下载 Index-Translate 2B 或 Hy-MT2 1.8B，每个约 1.1 GB。模型在 Transeen 内部运行，不需要账号、不需要另装应用，也不联网。需要 Apple 芯片的 Mac。首次翻译要几秒钟加载模型，空闲 5 分钟后自动释放内存。删除模型 可以再移除它。

大模型接口

任何兼容 OpenAI 的 chat/completions 接口。依次填写：

  • 接口地址，完整 URL，例如 https://api.openai.com/v1/chat/completions；
  • 模型名称；
  • 服务需要时填写 API Key，然后点 保存密钥，它会存进钥匙串。测试连接 可以检查是否可用。

本机上的服务也可以：本地地址可以用 HTTP，也不需要密钥，例如 Ollama 的 http://localhost:11434/v1/chat/completions。远程地址必须用 HTTPS。这种方式只发送识别出的文字，从不发送截图。请求失败时，Transeen 会显示错误并保留原图。

10常见问题排查

按 F1 没有反应

在笔记本键盘上，F1 默认调节亮度，需要按住 fn，或在系统设置 → 键盘 → 键盘快捷键 → 功能键中打开“将 F1、F2 等键用作标准功能键”。也可能是其他软件占用了 F1，Transeen 无法注册快捷键时会提示你。可以在设置 → 快捷键中换一个键，或从菜单栏菜单的 截图翻译 开始。

截图是空的，或一直提示授权

打开菜单栏菜单中的 屏幕权限…。如果系统设置里 Transeen 已经是打开的，先关掉再打开，然后选择 重新打开。

窗口有一块是黑的

有些软件会禁止录屏，保护视频等内容，这部分在任何截图里都是黑色。Transeen 读不到也翻译不了这部分，框里的其他内容照常翻译。

Apple 翻译没有开始

这对语言的语言包可能没有下载或还在下载。在设置 → 通用 → 翻译中下载，或到系统设置 → 通用 → 语言与地区 → 翻译语言中查看，然后再试一次。

本地模型启动不了

先重试一次。仍不行的话，在设置 → 通用 → 翻译中删除模型后重新下载；校验失败的下载会被自动删除。

部分文字翻译不对

密集排版、公式和专业术语可能让识别或翻译出错。按 Tab 对照原文，打开 文字 查看完整译文，或框选更小的区域。

11从源码构建

Transeen 以 MIT 许可证开源。需要 Xcode 26.4 或更高版本、Swift 6 和 XcodeGen。

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

应用会生成在 dist/Transeen.app。没有 Developer ID 证书时使用临时签名；设置 TRANSEEN_SIGNING_IDENTITY 可生成正式签名的版本。测试脚本是 ./scripts/test.sh、./scripts/test-license.sh 和 ./scripts/test-lifecycle.sh。托管的激活服务只属于官方版本，独立分发需要自己的授权后端。
