Fig 1.0  工作原理

一个键，四步。Transeen 读取你框住的像素，再把你的语言放回去，全程不离开这台 Mac。

  1. 1.1  框选

    框住看不懂的地方

    屏幕先定格。鼠标停在段落、输入框或窗口上会自动吸附，也可以自己拖一个框。

  2. 1.2  识别

    每一行在本机识别

    Apple 的 Vision 框架找出每一行文字和它的样式，不需要上传任何东西。

  3. 1.3  取字

    只把字取下来

    文字的笔画被单独取出，底下的背景重新补齐，渐变和纹理也一样。

  4. 1.4  落字

    译文回到原来的位置

    位置、字号、颜色都不变。只有放不下时，才会收窄或换行。

Fig 2.0  键盘

为键盘而做。原文永远只差一个键，上次截的位置也是。

F1

框选并翻译在任何应用里都能用。笔记本键盘上按 fn F1。

R

还是那块区域框选时按 R，直接截上一次的位置，重启后也记得。

Tab

原文与译文整张截图来回切换。

空格

偷看原文按住看原文，松开回到译文。

F1F1

交换语言截图开着时再按一次，换个方向翻译。

Fig 3.0  截图

截下来，接着用。截图停在你框选的位置，工具就在下面。

  • 直接标注

    矩形、椭圆、箭头、画笔和数字序号，六种颜色。标注在单独的图层上，切换语言也不会移位。

  • 漏了一行？拖一下边

    拖动边缘或四角，Transeen 从同一张定格画面重新裁切，松手后再翻译一次。

  • 钉在屏幕上，继续截

    钉住的截图浮在屏幕上，成为一张独立的图，想钉几张都行；右键可以复制、保存或切换原文。

  • 所见即所复制

    ⌘C 连同标注一起复制，译文还在陆续出现时也可以。⌘S 存为 PNG。

  • 当文字读

    打开完整译文，和原文并排列出，可以选中、复制。

  • 打开一张图片

    别人发来的截图也能翻。按 ⌘O 打开，工具完全一样。

Fig 4.0  翻译服务

三种翻译方式。在设置里选一种，随时可以换。文字识别始终在本机完成。

  • Apple 本机翻译 默认

    macOS 自带的翻译。语言包下载一次，之后离线可用。

    • 运行位置这台 Mac
    • 需要下载对应语言包
    • 出字方式每 8 行一组

  • 本地翻译模型 Apple 芯片

    Index-Translate 2B 或 Hy-MT2 1.8B，由 Transeen 自己运行。开发文档和界面文字译得更准。

    • 运行位置这台 Mac
    • 需要下载约 1.1 GB，下载后校验
    • 内存空闲 5 分钟后释放

  • 大模型接口 自选地址

    任意兼容 OpenAI 的 chat/completions 接口，远端走 HTTPS，也可以是本机 localhost 上的服务。

    • 发送内容只有识别出的文字
    • 密钥保存在钥匙串
    • 出字方式边返回边显示

截图永远不会离开你的 Mac。Transeen 不保存截图历史，也从不连续录屏。用 Apple 翻译或本地模型时，文字也留在本机。

Fig 5.0  语言

八种语言，任意互译。从其中任何一种译成另一种，原文语言可以自动识别。

应用本身也说你的语言：每个窗口、菜单和提示都跟随你选的母语。本来就是母语的页面，会译成你的另一种语言。

Fig 7.0  激活

一个激活码，一台 Mac，永久有效。不订阅，也不强制登录。

TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

永久授权 在菜单栏选择“激活与账号…”输入。
咨询激活码 怎么激活
  • 解锁截图、标注和翻译，适用于一台 Mac。
  • 无需登录即可激活。钥匙串里只保存一个随机安装 ID，从不读取序列号。

Fig 8.0  常见问题

常见问题。还有别的，到 GitHub Discussions 提问。

Transeen 支持哪些 Mac？

需要 macOS 26 或更高版本，Apple 芯片和 Intel 都支持，是同一个通用应用；本地翻译模型需要 Apple 芯片。应用界面跟随你选的母语，可选简体中文、繁體中文、English、日本語、한국어、Français、Español 和 Deutsch。

可以离线使用吗？

可以，激活之后即可。下载好语言包或本地模型后，截图、标注、Apple 翻译和本地模型都能离线运行。断网时授权依然有效，大约每天重新校验一次。大模型接口需要连接你设置的地址。

哪些数据会离开我的 Mac？

使用 Apple 翻译或本地模型时，没有：截图、识别出的文字和译文都留在这台 Mac 上。使用大模型接口时，只把识别出的文字发送到你设置的地址，不发送截图。激活时会发送激活码和一个随机安装 ID，检查更新会访问 GitHub。

可以换别的模型吗？

可以。在 设置 → 通用 → 翻译 里下载 Index-Translate 2B 或 Hy-MT2 1.8B（各约 1.1 GB），由 Transeen 自己在本机运行；也可以填写任意兼容 OpenAI 的 chat/completions 地址和模型名，需要时再填密钥，密钥保存在钥匙串中。远端地址必须使用 HTTPS；本机 localhost 上的服务可以用 HTTP，也可以不填密钥。

能翻译已有的图片吗？

可以。在启动面板选择“打开图片…”或按 ⌘O，图片会在同样的窗口里打开，工具也完全一样。

翻译准确吗？

取决于所选的翻译服务。密集排版、公式和专业术语可能需要修正；依赖某个细节之前，请按 Tab 对照原文，或打开完整译文核对。

Transeen 开源吗？

开源，采用 MIT 许可证，允许商业使用。官方应用需要 TR- 激活码；源码许可证不包含托管的激活服务，独立构建需要配置自己的授权后端。

怎么更新？

在菜单栏或启动面板选择“检查更新…”。Transeen 会查看 GitHub Releases，有新版本时打开下载页面。
