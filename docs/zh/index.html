你可能想了解

开始之前。

可以离线使用吗？

联网激活并下载 Apple 语言包后，截图、标注与 Apple 翻译可以离线使用。暂时断网时保留已有授权，应用会定期联网校验。外部模型需要相应网络连接。

截图会上传吗？

截图与 OCR 在本机处理。选择模型服务时，识别文字发送到你配置的接口。授权服务仅使用随机安装 ID 与回执，不读取硬件序列号。

源代码开源吗？

是，源代码采用 MIT 许可证，允许商业使用。官方安装包和托管授权服务使用激活码；MIT 许可证不授予该服务的访问权。

翻译效果有什么边界？

密集排版、公式与专业术语仍需核对。可随时对照原文，或在文字视图阅读完整结果。应用需要 macOS 26 或更高版本。
