开始之前。

支持哪些 Mac？
需要 macOS 26 或更高版本，同一安装包支持 Apple Silicon 与 Intel。当前应用界面为简体中文。
可以离线使用吗？
联网激活并下载 Apple 语言包后，截图、标注与 Apple 翻译可以离线使用。暂时断网时保留已有授权，应用会定期联网校验。外部模型需要相应网络连接。
开源和激活是什么关系？
源代码采用 MIT 许可证，允许商用、修改与分发。官方安装包需要 TR- 激活码；源码许可证不授予托管授权服务的访问权。
哪些内容需要核对？
密集排版、公式与专业术语仍需核对。重要信息请对照原文，也可以打开文字视图阅读完整译文。
如何检查更新？
在菜单栏或启动面板中选择“检查更新…”。Transeen 会检查最新 GitHub Release，发现新版本后可前往下载。
