Fig 1.0  工作原理

一个键，四步。全程在这台 Mac 上完成。

  1. 1.1  框选

    框住它

    屏幕先定格，自动吸附段落，也能自己拖框。

  2. 1.2  识别

    本机识别

    Apple Vision 找出每一行，不上传任何东西。

  3. 1.3  取字

    取下字迹

    文字取下来，下面的背景补回去。

  4. 1.4  落字

    放回原处

    位置、字号、颜色不变，换成你的语言。

Fig 2.0  任意软件

任意软件，也能跨软件。读的是屏幕像素，软件里什么都不用装。

  • 不用插件浏览器、聊天、PDF、游戏、远程桌面，选不中的字也行。
  • 一框跨多个软件不同软件的窗口，一次框进同一张截图。
  • 全屏和每个桌面打开着的菜单、提示都留在画面里。
  • 钉图浮在最上层切到哪个软件，译文都在旁边。

Fig 3.0  键盘

为键盘而做。原文永远只差一个键。

F1

翻译任何软件里都能按。

R

原地再截沿用上次的框。

Tab

切换原文或译文。

空格

偷看按住看原文。

F1F1

交换反过来翻译。

Fig 4.0  截图

截下来，接着用。工具就在下面。

  • 标注

    方框、箭头、画笔、序号，单独一层。

  • 拖一下边

    漏了一行？拖动边缘，自动重译。

  • 钉在屏幕上

    浮在屏幕上，继续截下一张。

  • 复制

    ⌘C 连标注一起复制。

  • 当文字读

    完整译文，直接复制。

  • 打开图片

    ⌘O 翻译已有的截图。

Fig 5.0  翻译服务

三种翻译方式。识别始终在本机。

  • Apple 本机翻译 默认

    macOS 自带，下载语言包后离线可用。

  • 本地模型 Apple 芯片

    Index-Translate 或 Hy-MT2，由 Transeen 自己运行。

  • 大模型接口 自选地址

    兼容 OpenAI 的接口，只发送文字。

截图永远不离开你的 Mac。不存历史，不连续录屏。

Fig 9.0  常见问题

常见问题。

支持哪些软件？

屏幕上显示文字的软件都行。Transeen 翻译的是你框住的像素，不需要插件，一个框还能同时框住几个软件。被软件禁止录屏的视频会显示成黑色，任何截图都一样。

支持哪些 Mac？

macOS 26 或更高版本，Apple 芯片和 Intel 都支持。本地模型需要 Apple 芯片。

可以离线使用吗？

可以，激活并下载好语言包或模型之后就行。只有大模型接口需要联网。

哪些数据会离开我的 Mac？

用 Apple 翻译或本地模型时，什么都不会。用大模型接口时，只把识别出的文字发到你设置的地址，从不发送截图。

可以换别的模型吗？

可以：在设置里下载 Index-Translate 2B 或 Hy-MT2 1.8B，或填写任意兼容 OpenAI 的接口。密钥保存在钥匙串里。

能翻译已有的图片吗？

可以。按 ⌘O 打开，工具完全一样。

翻译准确吗？

取决于翻译服务。依赖某个细节之前，按 Tab 对照一下原文。

Transeen 开源吗？

开源，采用 MIT 许可证。官方应用需要 TR- 激活码。

怎么更新？

在菜单栏选择“检查更新…”。
