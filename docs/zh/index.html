框选屏幕，
译文留在原处

按 ⌃⌥2 框选屏幕上的任意区域。Transeen 把文字换成你的语言，直接画回同一张图里。

下载 Mac 版

需要 macOS 26 或更高版本，以及 TR- 激活码。

English → 简体中文

在页面上拖动，或点击一段文字，选择要翻译的区域。聚焦页面后，方向键移动选区，按住 Shift 再按方向键调整大小。

一键切回原文

按 Tab 在原文和译文之间切换；按住空格可临时看原文；在任何应用里按 ⌃⌥空格 也能切换。

Transeen 的使用方式

先按 ⌃⌥2，
拖出范围

框选时画面保持静止。悬停会自动吸附段落或窗口，也可以自己拖出一块区域。

再在原处读译文

文字在这台 Mac 上识别，译文写回原来的位置，字号和颜色保持一致。

然后标出重点

矩形、箭头、画笔和编号都在独立图层上，切换语言也不会丢。

最后复制或钉住

⌘C 连同标注一起复制，⌘S 保存为 PNG，钉住的截图会浮在其他窗口上方。

常见问题

Transeen 支持哪些 Mac？

需要 macOS 26 或更高版本，Apple 芯片和 Intel 都支持，是同一个通用应用。应用界面目前为简体中文。

可以离线使用吗？

可以，激活之后即可。下载好语言包后，截图、标注和 Apple 翻译都能离线运行。断网时授权依然有效，大约每天重新校验一次。模型模式需要连接你设置的接口。

哪些数据会离开我的 Mac？

使用 Apple 翻译时，没有：截图、识别出的文字和译文都留在这台 Mac 上。模型模式只把识别出的文字发送到你设置的接口，不发送截图。激活时会发送激活码和一个随机安装 ID，检查更新会访问 GitHub。

可以用自己的模型吗？

可以。填写任意兼容 OpenAI 的 chat completions 地址和模型名，需要时再填密钥，密钥保存在钥匙串中。远端接口必须使用 HTTPS；本机 localhost 上的服务可以用 HTTP，也可以不填密钥。使用指南里有示例。

能翻译已有的图片吗？

可以。在启动面板选择“打开图片…”或按 ⌘O，图片会在同样的窗口里打开，工具也完全一样。

翻译准确吗？

取决于所选的翻译服务。密集排版、公式和专业术语可能需要修正；依赖某个细节之前，请按 Tab 对照原文，或打开完整文字核对。

Transeen 开源吗？

开源，采用 MIT 许可证，允许商业使用。官方应用需要 TR- 激活码；源码许可证不包含托管的激活服务，独立构建需要配置自己的授权后端。

怎么更新？

在菜单栏或启动面板选择“检查更新…”。Transeen 会查看 GitHub Releases，有新版本时打开下载页面。
