Fig 1.0  運作方式

一個鍵，四個步驟。Transeen 讀取你框住的像素，再把你的語言放回去，全程不離開這台 Mac。

  1. 1.1  框選

    框住看不懂的地方

    螢幕先定格。游標停在段落、輸入欄位或視窗上會自動吸附，也可以自己拖一個框。

  2. 1.2  辨識

    每一行都在本機辨識

    Apple 的 Vision 框架找出每一行文字和它的樣式，不需要上傳任何東西。

  3. 1.3  取字

    只取走字跡

    把文字從畫面上取下來，再補齊底下的背景，漸層和紋理也會還原。

  4. 1.4  落字

    譯文回到原本的位置

    位置、字級、顏色都不變。只有放不下時，才會縮窄或換行。

Fig 2.0  任何 App

任何 App，也能跨 App。Transeen 讀的是螢幕上的像素，所以文字出現在哪裡，就能在哪裡翻譯，App 裡什麼都不用裝。

  • 不用外掛，也不用整合瀏覽器、聊天軟體、PDF、遊戲、設計工具、遠端桌面，只要顯示在螢幕上就能翻。連選不起來、拷貝不了的字也可以。
  • 一個框跨好幾個 App一個框可以同時框住不同 App 的視窗，裡面的每一行都在同一張截圖裡翻譯。
  • 全螢幕 App 裡、每個桌面上都能用在全螢幕的 App 裡、任何一個桌面上都能按 F1。開著的選單、彈出視窗和提示會留在畫面裡，那個 App 也不會失去焦點。
  • 自動吸附眼前的內容游標停住，框就會找到底下的段落、輸入欄位或視窗，不管它屬於哪個 App。
  • 釘圖浮在所有 App 上方釘住的譯文會停在你切換到的任何 App 上方，可以一邊看譯文，一邊在原本的 App 裡操作。

Fig 3.0  鍵盤

為鍵盤而設計。原文永遠只差一個鍵，上次截圖的位置也是。

R

Fig 4.0  截圖

截下來，接著用。截圖停在你框選的位置，工具就在下方。

  • 直接標註

    矩形、橢圓、箭頭、畫筆和數字編號，六種顏色。標註在獨立的圖層上，切換語言也不會移位。

  • 漏了一行？拖一下邊

    拖動邊緣或四角，Transeen 會從同一張定格畫面重新裁切，放開後再翻譯一次。

  • 釘在螢幕上，繼續截

    釘住的截圖會浮在螢幕上，成為一張獨立的圖，想釘幾張都行；按右鍵可以拷貝、儲存或切換原文。

  • 所見即所拷貝

    ⌘C 連同標註一起拷貝，譯文還在陸續出現時也可以。⌘S 存成 PNG。

  • 當成文字讀

    打開完整譯文，和原文並排列出，可以選取、拷貝。

  • 打開一張圖片

    別人傳來的截圖也能翻。按 ⌘O 打開，工具完全一樣。

Fig 5.0  翻譯服務

三種翻譯方式。在設定裡選一種，隨時可以換。文字辨識一律在本機完成。

  • Apple 本機翻譯 預設

    macOS 內建的翻譯。語言包下載一次，之後就能離線使用。

    • 執行位置這台 Mac
    • 需要下載對應的語言包
    • 出字方式每 8 行一組

  • 本機翻譯模型 Apple 晶片

    Index-Translate 2B 或 Hy-MT2 1.8B，由 Transeen 自己執行。開發文件和介面文字譯得更準。

    • 執行位置這台 Mac
    • 需要下載約 1.1 GB，下載後驗證
    • 記憶體閒置 5 分鐘後釋放

  • 大模型介面 自選位址

    任何相容 OpenAI 的 chat/completions 介面，遠端走 HTTPS，也可以是本機 localhost 上的服務。

    • 傳送內容只有辨識出的文字
    • 金鑰存在鑰匙圈
    • 出字方式邊回傳邊顯示

截圖永遠不會離開你的 Mac。Transeen 不保存截圖紀錄，也從不持續錄影。使用 Apple 翻譯或本機模型時，文字也留在本機。

Fig 6.0  語言

八種語言，任意互譯。從其中任何一種譯成另一種，原文語言可以自動辨識。

Fig 7.0  更新紀錄

最近更新。小步快跑，完整紀錄在 GitHub 上。

0.11.22026 年 10 月 31 日

  • 圖片不再被當成字。文字旁邊的一排縮圖不會再被辨識成文字、擦掉後蓋上譯文。拿不準的一行會放大再讀一次，兩次讀得一樣才保留。

  • 解鎖截圖、標註與翻譯，適用於一台 Mac。

Fig 9.0  常見問題

常見問題。還有其他問題，歡迎到 GitHub Discussions 提問。

支援哪些 App？

螢幕上會顯示文字的 App 都可以：瀏覽器、聊天和郵件、PDF 閱讀器、遊戲、設計與影片工具、遠端桌面和虛擬機器。Transeen 翻譯的是你框住的像素，不需要外掛，也不需要 App 本身支援；一個框還能同時框住好幾個 App 的視窗。被 App 設為禁止螢幕錄製的影片會顯示成黑色，任何截圖都一樣。

Transeen 支援哪些 Mac？

需要 macOS 26 或更新版本，Apple 晶片和 Intel 都支援，是同一個通用 App；本機翻譯模型需要 Apple 晶片。App 介面會跟隨你選的母語，可選简体中文、繁體中文、English、日本語、한국어、Français、Español 和 Deutsch。

可以離線使用嗎？

可以，啟用之後就行。下載好語言包或本機模型後，截圖、標註、Apple 翻譯和本機模型都能離線執行。斷網時授權依然有效，大約每天重新驗證一次。大模型介面需要連線到你設定的位址。

哪些資料會離開我的 Mac？

使用 Apple 翻譯或本機模型時，沒有：截圖、辨識出的文字和譯文都留在這台 Mac 上。使用大模型介面時，只會把辨識出的文字傳送到你設定的位址，不會傳送截圖。啟用時會傳送啟用碼和一個隨機安裝 ID，檢查更新會連到 GitHub。

可以換別的模型嗎？

可以。在 設定 → 一般 → 翻譯 裡下載 Index-Translate 2B 或 Hy-MT2 1.8B（各約 1.1 GB），由 Transeen 自己在本機執行；也可以填寫任何相容 OpenAI 的 chat/completions 位址和模型名稱，需要時再填金鑰，金鑰會存在鑰匙圈中。遠端位址必須使用 HTTPS；本機 localhost 上的服務可以用 HTTP，也可以不填金鑰。

能翻譯已經有的圖片嗎？

可以。在啟動面板選擇「打開圖片…」或按 ⌘O，圖片會在同樣的視窗裡打開，工具也完全一樣。

翻譯準確嗎？

取決於所選的翻譯服務。密集的版面、公式和專業術語可能需要修正；在依賴某個細節之前，請按 Tab 對照原文，或打開完整譯文核對。

Transeen 開源嗎？

開源，採用 MIT 授權條款，允許商業使用。官方 App 需要 TR- 啟用碼；原始碼授權不包含代管的啟用服務，獨立建置需要設定自己的授權後端。

怎麼更新？

在選單列或啟動面板選擇「檢查更新…」。Transeen 會查看 GitHub Releases，有新版本時打開下載頁面。
