Transeen/使用指南

五個步驟裝好 Transeen，然後按 F1。

從下載到第一次截圖翻譯。你需要一台 macOS 26 或更新版本的 Mac，和一組 TR- 啟用碼。

01安裝

  1. 從 GitHub Releases 下載最新的 DMG。大約 10 MB，一個通用版本同時支援 Apple 晶片和 Intel。
  2. 打開 DMG，把 Transeen 拖進「應用程式」。
  3. 從「應用程式」打開 Transeen。它常駐在選單列，不在 Dock 裡，請在選單列找它的圖像。

App 和 DMG 都以 Developer ID 簽署並通過 Apple 公證，macOS 打開時不會跳出警告。同一個發布頁還有 ZIP 和 SHA-256 檢查碼。介面語言會跟隨系統：简体中文、繁體中文、English、日本語、한국어、Français、Español、Deutsch。

02啟用

  1. 在選單列選單中選擇 啟用與帳號…，或在主視窗中選擇 啟用 Transeen。
  2. 輸入啟用碼，格式是 TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX，然後選擇 啟用這台 Mac。不需要登入。
  3. 如果願意，可以用 Google、GitHub 或電子郵件登入 iTool 帳號並綁定授權。之後登入同一個帳號就能恢復。

啟用只會在鑰匙圈裡保存一個隨機安裝 ID 和一份憑證，不會讀取 Mac 的序號。一組啟用碼對應一台 Mac，綁定帳號不會多出一份授權。StupidMirror 的 SM- 和 iTool Pro 的 IT- 啟用碼屬於其他產品，在這裡不能用。想要啟用碼，請到 GitHub Discussions 留言。

03開啟螢幕錄製

第一次截圖時，Transeen 會要求螢幕錄製權限。它只使用螢幕畫面，不錄音，而且只在你按下截圖快速鍵時才擷取。它不保存紀錄，也從不持續錄影。

  1. 選擇 打開系統設定…，或前往系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製。
  2. 找到 Transeen 並打開開關。
  3. 回到 Transeen。它會自動重新檢查並顯示 已準備好，選擇 開始框選 繼續。

如果開關已經打開卻還是沒有作用，在同一個視窗裡點 重新檢查 或 重新打開。

04選擇語言

主視窗有兩個選單：原文語言 和 譯文語言。原文可以維持 自動識別，也可以從八種語言中選一種：簡體中文、繁體中文、英文、日文、韓文、法文、西班牙文、德文。任兩種之間都能互譯。

截圖打開時，工具下方的方向（例如 JA → 繁中）可以改任一邊的語言；再按一次 F1 就交換兩邊。

Apple 翻譯的每一組語言都需要語言包。第一次啟動時的導覽，以及之後的設定 → 一般 → 翻譯，會列出譯文語言需要的語言包和狀態。點 下載 先裝好，第一次截圖就不用等；之後翻譯完全在本機離線完成。語言包也可以在系統設定 → 一般 → 語言與地區 → 翻譯語言中查看。

05框選翻譯

  1. 在任何 App 裡按 F1。螢幕會定格並變暗。在筆電鍵盤上是 fn F1，除非你把 F 鍵設成了標準功能鍵。
  2. 移動游標會自動吸附到段落、輸入欄位或視窗，點一下即可；也可以自己拖一個框，一個框可以跨過好幾個 App 的視窗。Esc 或按右鍵取消。
  3. 和上次同一個位置？框選時按 R，直接沿用上一次截圖的區域，重新開機後也有效。
  4. 譯文會出現在原文所在的位置，一行翻好就顯示一行。按 Tab 在原文和譯文之間切換，按住 空白鍵 暫時看原文。
  5. 少框了一點？拖動截圖的邊或角。它會從同一張定格畫面重新裁切，標註留在原處，放開後重新翻譯。
  6. 方向反了？截圖打開時再按一次 F1，兩種語言會對調。

Transeen 讀的是螢幕像素，所以在每個 App 裡用法都一樣，全螢幕 App 和每個桌面也包括在內，開著的選單或提示也會留在畫面裡。F1 是預設唯一在任何 App 裡都能用的快速鍵。只想截圖標註、不翻譯，可以在選單列選單中選擇 截圖標註，或在設定 → 快速鍵中替它指定一個鍵；在那個視窗裡按 T 仍然可以翻譯。要翻譯已經有的圖片，選擇 打開圖片… 或按 ⌘O。

06標註

在工具列選工具，或直接按鍵：R 矩形、O 橢圓、A 箭頭、P 畫筆、V 選擇與移動。繪圖工具一按就畫，從現有的標註上起筆也一樣；要拿起某個標註，請用 V。編號標註從 1 開始遞增，還原和重做後編號不變。

有六種顏色和三種粗細可選，也可以打開滑桿選任何顏色和 1 到 10 的線寬。⌘Z 和 ⌘⇧Z 還原、重做，Delete 刪除選取的標註。標註在獨立的圖層上，切換原文和譯文時不會移動。

07拷貝、儲存或釘圖

  • ⌘C 依照你看到的樣子拷貝圖片，包含標註，即使譯文還在產生也可以。預設拷貝後會關閉截圖；在設定中關掉 拷貝後關閉截圖 就能保留。
  • ⌘S 存成 PNG。
  • 釘到螢幕 把圖片留在螢幕上，成為一個獨立的浮動視窗，同時結束這次截圖，馬上可以截下一張。釘圖會停在你切換到的 App 上方，可以拖到任何地方，想留幾張都行；按右鍵可以拷貝、儲存、切換原文和譯文或關閉。
  • 文字 打開完整譯文，與原文並排，方便拷貝。

08選擇翻譯服務

打開設定（⌘,）→ 一般 → 翻譯，選擇 翻譯服務。文字辨識一律在本機完成。

Apple 本機翻譯

預設選項。使用第 4 步的語言包，離線執行，不會把內容傳到任何地方。文字每 8 行一組翻譯，長截圖會邊看邊補滿。

本機翻譯模型

下載 Index-Translate 2B 或 Hy-MT2 1.8B，每個約 1.1 GB。模型在 Transeen 內部執行，不需要帳號、不需要另外安裝 App，也不連網。需要 Apple 晶片的 Mac。第一次翻譯要花幾秒載入模型，閒置 5 分鐘後會自動釋放記憶體。刪除模型 可以再把它移除。

大模型介面

任何相容 OpenAI 的 chat/completions 介面。依序填寫：

  • 介面位址，完整的 URL，例如 https://api.openai.com/v1/chat/completions；
  • 模型名稱；
  • 服務需要時填寫 API Key，然後點 儲存金鑰，它會存進鑰匙圈。測試連線 可以檢查能不能用。

本機上的服務也可以：本機位址可以用 HTTP，也不需要金鑰，例如 Ollama 的 http://localhost:11434/v1/chat/completions。遠端位址必須使用 HTTPS。這種方式只傳送辨識出的文字，從不傳送截圖。請求失敗時，Transeen 會顯示錯誤並保留原圖。

每一項都能在設定 → 快速鍵中修改，恢復全部預設快速鍵 可以還原。截圖標註 和 全域對照原文 預設沒有按鍵，需要在那裡設定。全域快速鍵需要搭配 ⌘、⌥ 或 ⌃，也可以用 F 功能鍵。

10疑難排解

按 F1 沒有反應

在筆電鍵盤上，F1 預設是調整亮度，需要按住 fn，或在系統設定 → 鍵盤 → 鍵盤快速鍵 → 功能鍵中打開「將 F1、F2 等鍵作為標準功能鍵使用」。也可能是其他 App 佔用了 F1，Transeen 無法註冊快速鍵時會提示你。可以在設定 → 快速鍵中換一個鍵，或從選單列選單的 截圖翻譯 開始。

截圖是空的，或一直要求授權

打開選單列選單中的 螢幕權限…。如果系統設定裡 Transeen 已經是打開的，先關掉再打開，然後選擇 重新打開。

視窗有一塊是黑的

有些 App 會禁止螢幕錄製，保護影片等內容，這部分在任何截圖裡都是黑色。Transeen 讀不到也翻譯不了這部分，框裡的其他內容照常翻譯。

Apple 翻譯沒有開始

這組語言的語言包可能還沒下載或正在下載。在設定 → 一般 → 翻譯中下載，或到系統設定 → 一般 → 語言與地區 → 翻譯語言中查看，然後再試一次。

本機模型無法啟動

先重試一次。還是不行的話，在設定 → 一般 → 翻譯中刪除模型後重新下載；驗證失敗的下載會自動刪除。

部分文字翻得不對

密集的版面、公式和專業術語可能讓辨識或翻譯出錯。按 Tab 對照原文，打開 文字 查看完整譯文，或框選小一點的區域。

11從原始碼建置

Transeen 以 MIT 授權條款開源。需要 Xcode 26.4 或更新版本、Swift 6 和 XcodeGen。

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

App 會產生在 dist/Transeen.app。沒有 Developer ID 憑證時會使用臨時簽署；設定 TRANSEEN_SIGNING_IDENTITY 可以產生正式簽署的版本。測試指令碼是 ./scripts/test.sh、./scripts/test-license.sh 和 ./scripts/test-lifecycle.sh。代管的啟用服務只屬於官方版本，獨立發行需要自己的授權後端。
