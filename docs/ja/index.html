Fig 1.0  仕組み

キーひとつ、4 ステップ。すべて Mac の中で。

  1. 1.1  選ぶ

    囲む

    画面が静止。段落に吸着するか、自分で囲みます。

  2. 1.2  認識

    Mac で読む

    Apple Vision が各行を見つけます。送信はしません。

  3. 1.3  取り出す

    文字を外す

    文字だけを外し、下の背景を復元します。

  4. 1.4  置く

    元の場所へ

    位置も大きさも色もそのまま、あなたの言語で。

Fig 2.0  どのアプリでも

どのアプリでも、アプリをまたいでも。画面のピクセルを読むので、アプリ側には何も要りません。

  • プラグイン不要ブラウザ、チャット、PDF、ゲーム、リモートデスクトップ。選択できない文字も。
  • 複数のアプリを一度に別々のアプリのウインドウを、1 枚のキャプチャで囲めます。
  • フルスクリーンでも開いたメニューやツールチップも画像に残ります。
  • ピンは最前面にどのアプリに切り替えても、訳文はそばに。

Fig 4.0  キャプチャ

撮ったあとも使える。ツールはすぐ下に。

  • 注釈

    四角、矢印、ペン、番号を別レイヤーに。

  • 端を引っ張る

    1 行足りなければ、端をドラッグして再翻訳。

  • ピン留め

    画面に浮かべたまま、次のキャプチャへ。

  • コピー

    ⌘C で注釈ごとコピー。

  • テキストで読む

    訳文の全文を、そのままコピー。

  • 画像を開く

    ⌘O で手元のスクリーンショットも。

Fig 5.0  翻訳

翻訳の方法は 3 つ。認識は常に Mac の中。

  • Apple 翻訳 標準

    macOS 内蔵。言語パックを入れればオフライン。

  • ローカルモデル Apple シリコン

    Index-Translate か Hy-MT2 を Transeen が実行。

  • LLM API 任意の接続先

    OpenAI 互換の API。送るのは文字だけ。

スクリーンショットは Mac から出ません。履歴も、連続録画もなし。

Fig 9.0  よくある質問

よくある質問。

どのアプリで使えますか？

画面に文字を表示するアプリならどれでも。選んだ範囲のピクセルを翻訳するのでプラグインは不要で、ひとつの範囲で複数のアプリを囲めます。画面収録から保護された動画は、ほかのスクリーンショットと同じく黒く写ります。

どの Mac で使えますか？

macOS 26 以降の Apple シリコン搭載 Mac と Intel Mac。ローカルモデルには Apple シリコンが必要です。

オフラインで使えますか？

はい。アクティベートし、言語パックかモデルをダウンロードしておけば使えます。LLM API だけはネットワークが必要です。

Mac の外に何が送られますか？

Apple 翻訳かローカルモデルなら何も送りません。LLM API では認識した文字だけを接続先に送り、スクリーンショットは送りません。

別のモデルを使えますか？

はい。設定で Index-Translate 2B か Hy-MT2 1.8B をダウンロードするか、OpenAI 互換の API を入力します。キーはキーチェーンに保存されます。

手元の画像も翻訳できますか？

はい。⌘O で開くと、同じツールが使えます。

翻訳の精度は？

翻訳サービスによります。細かい点を頼りにする前に、Tab で原文を確かめてください。

Transeen はオープンソースですか？

はい、MIT ライセンスです。公式の App には TR- コードが必要です。

アップデートの方法は？

メニューバーで「アップデートを確認…」を選びます。

F1 を押して、最初に読めなかったところを選んでください。
