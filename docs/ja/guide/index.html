Transeen の準備は、5 つのステップ。

ダウンロードから、最初のスクリーンショットを翻訳するまで。macOS 26 以降の Mac と、TR- アクティベーションコードが必要です。

01インストール

  1. GitHub Releases から最新の DMG をダウンロードします。約 10 MB で、Apple シリコンと Intel の両方に対応したユニバーサル App です。
  2. DMG を開き、Transeen をアプリケーションフォルダにドラッグします。
  3. アプリケーションフォルダから Transeen を開きます。メニューバーで動作するので、Dock ではなくメニューバーのアイコンを探してください。

App と DMG は Developer ID で署名され、Apple の公証を受けているので、macOS は警告なしで開きます。同じリリースページに ZIP と SHA-256 チェックサムもあります。画面表示は Mac の言語に合わせます：English、简体中文、繁體中文、日本語、한국어、Français、Español、Deutsch。

02アクティベート

  1. メニューバーのメニューで アクティベーションとアカウント… を、またはホームウインドウで Transeen をアクティベート を選びます。
  2. TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX の形式のコードを入力し、この Mac をアクティベート を選びます。ログインは不要です。
  3. 必要なら Google、GitHub、メールで iTool アカウントにログインし、ライセンスを連携します。あとで同じアカウントにログインすれば復元できます。

アクティベーションでは、ランダムなインストール ID とレシートをキーチェーンに保存するだけで、Mac のシリアル番号は読み取りません。1 つのコードで Mac 1 台分です。アカウントに連携してもライセンスは増えません。StupidMirror の SM- コードと iTool Pro の IT- コードは別製品のもので、ここでは使えません。コードの入手は GitHub Discussions で問い合わせてください。

03画面収録を許可

初めてキャプチャするとき、Transeen は画面収録の許可を求めます。使うのは画面の画像だけで、音声は使いません。キャプチャのショートカットを押したときにしか画面を取得せず、履歴も残さず、録画し続けることもありません。

  1. システム設定を開く… を選ぶか、システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 を開きます。
  2. Transeen を見つけてオンにします。
  3. Transeen に戻ります。自動で確認し直して 準備完了 と表示されたら、範囲を選択 で続けます。

オンにしても反映されない場合は、同じウインドウで 再確認 か 開き直す を使ってください。

04言語を選ぶ

ホームウインドウには 原文の言語 と 翻訳先の言語 の 2 つのメニューがあります。原文は 自動検出 のままにするか、8 つの言語から選びます：簡体字中国語、繁体字中国語、英語、日本語、韓国語、フランス語、スペイン語、ドイツ語。どの言語からでも他のどの言語にも翻訳できます。

キャプチャを開いているときは、ツールの下にある方向（例：EN → JA）でどちらの言語も変えられます。もう一度 F1 を押すと入れ替わります。

Apple 翻訳には、言語の組み合わせごとに言語パックが必要です。初回起動時のガイドと、その後は 設定 → 一般 → 翻訳 に、翻訳先の言語に必要なパックと状態が表示されます。ダウンロード で先に入れておけば、最初のキャプチャで待ちません。以後の翻訳は Mac 上でオフラインで行われます。言語パックは システム設定 → 一般 → 言語と地域 → 翻訳言語 でも確認できます。

05範囲を翻訳

  1. どのアプリでも F1 を押します。画面が静止して暗くなります。ノートパソコンのキーボードでは fn F1 です（F キーを標準のファンクションキーとして使う設定にしている場合を除く）。
  2. ポインタを合わせて段落や入力欄、ウインドウに吸着させてクリックするか、自分で範囲をドラッグします。範囲は複数のアプリのウインドウにまたがっても構いません。Esc か右クリックでキャンセルします。
  3. 前回と同じ場所なら、範囲を選ぶときに R を押すと前回のキャプチャの範囲をもう一度使います。再起動後も有効です。
  4. 訳文は元の文字があった場所に表示され、翻訳できた行から順に出てきます。Tab で原文と訳文を切り替え、スペース を押し続けると原文をのぞけます。
  5. 少し足りなければ、キャプチャの端か角をドラッグします。同じ静止画面から切り抜き直し、注釈はそのままに、離すともう一度翻訳します。
  6. 向きが逆なら、キャプチャを開いたまま F1 をもう一度押すと 2 つの言語が入れ替わります。

Transeen は画面のピクセルを読むので、フルスクリーンのアプリやどの操作スペースでも、どのアプリでも同じように使えます。開いているメニューやツールチップも画像に残ります。最初からどのアプリでも使えるショートカットは F1 だけです。翻訳せずに注釈だけ付けたいときは、メニューバーのメニューで 注釈 を選ぶか、設定 → ショートカット でキーを割り当てます。そのウインドウで T を押せば、あとから翻訳もできます。手元の画像を翻訳するには 画像を開く… を選ぶか ⌘O を押します。

06注釈を付ける

ツールバーでツールを選ぶか、キーを押します：R 四角形、O 楕円、A 矢印、P ペン、V 選択と移動。描画ツールは、既存の注釈の上から描き始めても必ず描きます。注釈をつかむときは V を使います。番号は 1 から増えていき、取り消しややり直しをしても変わりません。

6 色と 3 種類の太さから選ぶか、スライダーで任意の色と 1〜10 の線の太さを選べます。⌘Z と ⌘⇧Z で取り消しとやり直し、Delete で選択した注釈を削除します。注釈は別のレイヤーにあるので、原文と訳文を切り替えても動きません。

07コピー、保存、ピン留め

  • ⌘C で、注釈を含めて見たままの画像をコピーします。翻訳の途中でも使えます。標準ではコピーするとキャプチャも閉じます。開いたままにするには、設定で コピー後にキャプチャを閉じる をオフにします。
  • ⌘S で PNG に保存します。
  • 画面にピン留め は、画像を独立した浮動ウインドウとして画面に残し、キャプチャを終えるので、すぐに次のキャプチャを始められます。ピンは切り替えた先のアプリの上にとどまります。どこにでもドラッグでき、いくつでも残せます。右クリックでコピー、保存、原文と訳文の切り替え、閉じるができます。
  • テキスト で、訳文の全文を原文と並べて開き、そのままコピーできます。

08翻訳サービスを選ぶ

設定（⌘,）→ 一般 → 翻訳 で 翻訳サービス を選びます。文字の認識は常に Mac 上で行います。

Apple 翻訳（本機）

標準の設定です。ステップ 4 の言語パックを使い、オフラインで動き、どこにも何も送りません。8 行ずつ翻訳するので、長いキャプチャも読み進めるうちに埋まっていきます。

ローカル翻訳モデル

Index-Translate 2B か Hy-MT2 1.8B（それぞれ約 1.1 GB）をダウンロードします。モデルは Transeen の中で動き、アカウントも追加のアプリもネットワークも要りません。Apple シリコン搭載の Mac が必要です。最初の翻訳ではモデルの読み込みに数秒かかり、5 分使わないとメモリを解放します。モデルを削除 で取り除けます。

LLM API

OpenAI 互換の chat/completions エンドポイントなら何でも使えます。次の項目を入力します：

  • エンドポイント：完全な URL。例 https://api.openai.com/v1/chat/completions
  • モデル名
  • サービスが必要とする場合は API キーを入力して キーを保存。キーはキーチェーンに保存されます。接続をテスト で確認できます。

自分の Mac で動かすサーバも使えます。ローカルのアドレスは HTTP のままでよく、キーも不要です。例えば Ollama なら http://localhost:11434/v1/chat/completions。リモートのアドレスには HTTPS が必要です。このモードで送るのは認識した文字だけで、スクリーンショットは送りません。リクエストが失敗すると、Transeen はエラーを表示して元の画像を残します。

10困ったときは

F1 を押しても何も起きない

ノートパソコンのキーボードでは、fn を押さないと F1 は明るさの調整になります。または システム設定 → キーボード → キーボードショートカット → ファンクションキー で「F1、F2 などのキーを標準のファンクションキーとして使用」をオンにします。他のアプリが F1 を使っている場合もあり、ショートカットを登録できないときは Transeen が知らせます。設定 → ショートカット で別のキーを選ぶか、メニューバーのメニューの キャプチャして翻訳 から始めてください。

キャプチャが空になる、または許可を何度も求められる

メニューバーのメニューで 画面収録の許可… を開きます。システム設定ですでに Transeen がオンになっている場合は、いったんオフにしてからオンに戻し、開き直す を選びます。

ウインドウの一部が黒くなる

動画などを画面収録から保護しているアプリがあり、その部分はどのスクリーンショットでも黒く写ります。Transeen もその部分は読めず翻訳できませんが、範囲内のほかの部分はいつも通り翻訳されます。

Apple 翻訳が始まらない

その言語の組み合わせの言語パックがないか、ダウンロード中かもしれません。設定 → 一般 → 翻訳 でダウンロードするか、システム設定 → 一般 → 言語と地域 → 翻訳言語 を確認してから、もう一度試してください。

ローカルモデルが起動しない

一度やり直してください。それでもだめなら、設定 → 一般 → 翻訳 でモデルを削除してダウンロードし直します。チェックサムの検証に失敗したダウンロードは自動で削除されます。

一部の文字がおかしく訳される

込み入ったレイアウトや数式、専門用語は、認識や翻訳を誤らせることがあります。原文と比べる（Tab）、テキスト で全文を開く、範囲を小さくする、のいずれかを試してください。

11ソースからビルド

Transeen は MIT ライセンスです。Xcode 26.4 以降、Swift 6、XcodeGen が必要です。

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

App は dist/Transeen.app に書き出されます。Developer ID がない場合はアドホック署名になります。署名付きでビルドするには TRANSEEN_SIGNING_IDENTITY を設定します。テストは ./scripts/test.sh、./scripts/test-license.sh、./scripts/test-lifecycle.sh です。ホスト型のアクティベーションサービスは公式の App のものなので、独自に配布する場合は独自のライセンスバックエンドが必要です。
