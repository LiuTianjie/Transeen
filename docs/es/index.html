Una tecla, cuatro pasos. Todo en tu Mac.

  1. 1.1  Seleccionar

    Enmárcalo

    La pantalla se congela. Ajústate a un párrafo o dibuja tu marco.

  2. 1.2  Reconocer

    Se lee en tu Mac

    Apple Vision encuentra cada línea. No se sube nada.

  4. 1.4  Colocar

Fig 2.0  Cualquier app

En cualquier app, y entre apps. Transeen lee los píxeles: no hay nada que instalar en la app.

  • Sin extensionesNavegadores, chats, PDF, juegos, escritorios remotos. Incluso texto que no puedes seleccionar.
  • Un marco, varias appsVentanas de varias apps en una sola captura.
  • También a pantalla completaLos menús y las ayudas abiertos se quedan en la imagen.
  • Lo fijado queda delanteLa traducción se queda junto a la app en la que trabajas.

Fig 4.0  La captura

Una captura con la que trabajar. Las herramientas, justo debajo.

  • Anota

    Recuadros, flechas, lápiz y números, en su propia capa.

  • Tira de un borde

    ¿Te faltó una línea? Arrastra el borde y se vuelve a traducir.

  • Fíjala

    Déjala en la pantalla y sigue capturando.

  • Cópiala

    ⌘C copia lo que ves, con las anotaciones.

  • Léela como texto

    La traducción completa, lista para copiar.

  • Abre una imagen

    ⌘O para capturas que ya tienes.

Fig 5.0  Traducción

Tres formas de traducir. El reconocimiento siempre se queda en tu Mac.

  • Traducción de Apple Predeterminada

    Integrada en macOS. Sin conexión con el paquete de idioma.

  • Modelo local Chip de Apple

    Index-Translate o Hy-MT2, ejecutado por Transeen.

  • API de LLM Tu endpoint

    Cualquier API compatible con OpenAI. Solo se envía el texto.

La captura nunca sale de tu Mac. Sin historial ni grabación continua.

Fig 9.0  Preguntas

Preguntas.

¿Con qué apps funciona?

Con cualquier app que muestre texto en pantalla. Transeen traduce los píxeles que seleccionas, así que no necesita extensiones, y un marco puede abarcar varias apps. El vídeo protegido de la grabación de pantalla sale en negro, como en cualquier captura.

¿En qué Mac funciona?

En macOS 26 o posterior, con chip de Apple o Intel. Los modelos locales necesitan un chip de Apple.

¿Funciona sin conexión?

Sí, una vez activado y descargado el paquete de idioma o el modelo. Solo una API de LLM necesita conexión.

¿Qué sale de mi Mac?

Con la Traducción de Apple o un modelo local, nada. Con una API de LLM, solo el texto reconocido va a tu endpoint, nunca la captura.

¿Puedo usar otro modelo?

Sí: descarga Index-Translate 2B o Hy-MT2 1.8B en Ajustes, o introduce una API compatible con OpenAI. Las claves se guardan en tu llavero.

¿Puede traducir una imagen que ya tengo?

Sí. Pulsa ⌘O y se abre con las mismas herramientas.

¿Qué precisión tiene?

Depende del servicio de traducción. Pulsa Tab para revisar el original antes de fiarte de un detalle.

¿Transeen es de código abierto?

Sí, con licencia MIT. La app oficial necesita un código TR-.

¿Cómo se actualiza?

Elige Buscar actualizaciones… en la barra de menús.
