Transeen/Setup guide

Set up Transeen in five steps.

From the download to your first translated screenshot. You need a Mac with macOS 26 or later and a TR- activation code.

01Install

  1. Download the latest DMG from GitHub Releases. It is about 10 MB, one universal app for Apple silicon and Intel.
  2. Open the DMG and drag Transeen to Applications.
  3. Open Transeen from Applications. It lives in the menu bar, so look for its icon there rather than in the Dock.

The app and the DMG are signed with a Developer ID and notarized by Apple, so macOS opens them without a warning. A ZIP and SHA-256 checksums are on the same release page. The interface follows your Mac’s language: English, 简体中文, 繁體中文, 日本語, 한국어, Français, Español or Deutsch.

02Activate

  1. Choose Activation & Account… in the menu bar menu, or Activate Transeen in the home window.
  2. Enter your code, which looks like TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX, and choose Activate This Mac. No sign-in is needed.
  3. If you like, sign in to an iTool account with Google, GitHub or email and link the license. Signing in to the same account later restores it.

Activation keeps a random installation ID and a receipt in your Keychain; it never reads your Mac’s serial number. One code covers one Mac, and linking an account does not create a second license. StupidMirror SM- and iTool Pro IT- codes are separate products and don’t work here. To get a code, ask in GitHub Discussions.

03Allow screen recording

The first time you capture, Transeen asks for the Screen Recording permission. It uses the screen image only, never audio, and only when you press a capture shortcut. It keeps no history and never records continuously.

  1. Choose Open System Settings…, or go to System Settings → Privacy & Security → Screen & System Audio Recording.
  2. Find Transeen and turn it on.
  3. Come back to Transeen. It checks again by itself and shows All Set; choose Select an Area to carry on.

If it is on but still not working, use Check Again or Reopen in the same window.

04Choose languages

The home window has two menus, Source Language and Target Language. Leave the source on Auto Detect or choose one of the eight languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, Spanish and German. Any of them translates into any other.

On an open capture, the direction under the tools (for example JA → EN) changes either language, and pressing F1 again swaps them.

Apple Translation needs a language pack for each pair. The guide that opens on first launch, and Settings → General → Translation later, list the packs for your target language with their status. Download fetches one before your first capture needs it; after that the translation runs on your Mac, offline. Packs are also listed in System Settings → General → Language & Region → Translation Languages.

05Translate a region

  1. Press F1. The screen holds still and dims. On a laptop keyboard that is fn F1, unless the F keys work as standard function keys.
  2. Hover to snap to a paragraph, a field or a window and click, or drag a frame of your own. Esc or a right click cancels.
  3. Same place as last time? Press R while selecting and the last capture’s area is taken again, even after a restart.
  4. Read the translation where the text was. Lines appear as they are translated. Press Tab to switch to the original and back, or hold Space to peek at it.
  5. Missed a bit? Drag an edge or corner of the capture. It re-crops from the same frozen screen, keeps your marks in place and translates again when you let go.
  6. Wrong way round? Press F1 again while the capture is open and the two languages swap.

F1 is the only shortcut that works from any app out of the box. To capture for marking up without translating, choose Markup in the menu bar menu, or give it a key in Settings → Shortcuts; press T in that window if you want the translation after all. To translate a picture you already have, choose Open Image… or press ⌘O.

06Mark it up

Choose a tool on the toolbar or press its key: R for a rectangle, O for an ellipse, A for an arrow, P for the pen and V to select and move. Numbered notes count up from 1 and keep their numbers through undo and redo.

Pick one of six colors and three widths, or open the sliders for any color and a width from 1 to 10. ⌘Z and ⌘⇧Z undo and redo; Delete removes the selected mark. Marks sit on their own layer, so switching between original and translation never moves them.

07Copy, save or pin

  • ⌘C copies the picture as you see it, marks included, even while a translation is still running. By default this also closes the capture; turn off Close capture after copying in Settings to keep it open.
  • ⌘S saves it as a PNG.
  • Pin to Screen leaves the picture on the screen as a floating window of its own and ends the capture, so the next one can start straight away. Drag a pin anywhere and keep as many as you need; right-click one to copy, save, switch between original and translation or close it.
  • Text opens the full translation next to the original, ready to copy.

08Pick a translation service

Open Settings (⌘,) → General → Translation and choose a Translation Service. Text recognition always happens on your Mac.

Apple Translation (on device)

The default. It uses the language packs from step 4, runs offline and sends nothing anywhere. Lines are translated in groups of eight, so a long capture fills in as you read.

Local Translation Model

Download Index-Translate 2B or Hy-MT2 1.8B, about 1.1 GB each. The model runs inside Transeen, with no account, no extra app and no network. It needs a Mac with Apple silicon. The first translation takes a few seconds to load the model, and its memory is freed after five idle minutes. Delete Model removes it again.

LLM API

Any OpenAI-compatible chat/completions endpoint. Fill in:

  • Endpoint, the full URL, for example https://api.openai.com/v1/chat/completions;
  • Model Name;
  • the API key, if the service needs one, then Save Key. It is stored in your Keychain. Test Connection checks it.

A server on your own Mac works too: local addresses may use plain HTTP and need no key, for example http://localhost:11434/v1/chat/completions for Ollama. Remote addresses must use HTTPS. This mode sends only the recognized text, never the screenshot. If a request fails, Transeen shows the error and keeps the original picture.

10Troubleshooting

Nothing happens when I press F1

On a laptop keyboard F1 changes the brightness unless you hold fn, or turn on “Use F1, F2, etc. keys as standard function keys” in System Settings → Keyboard → Keyboard Shortcuts → Function Keys. Another app may also hold F1; Transeen tells you when it cannot register a shortcut. Choose a different key in Settings → Shortcuts, or start from Capture & Translate in the menu bar menu.

The capture is empty or the permission keeps asking

Open Screen Permission… in the menu bar menu. If System Settings already shows Transeen turned on, turn it off and on again, then choose Reopen.

Apple Translation does not start

The language pack for that pair may be missing or still downloading. Download it in Settings → General → Translation, or check System Settings → General → Language & Region → Translation Languages, and try again.

The local model doesn’t start

Try again once. If it still fails, delete the model in Settings → General → Translation and download it again; a download that fails its checksum is deleted for you.

Some text comes out wrong

Dense layouts, formulas and specialist terms can trip up recognition or translation. Compare with the original (Tab), open Text for the full translation, or select a smaller region.

11Build from source

Transeen is MIT licensed. You need Xcode 26.4 or later, Swift 6 and XcodeGen.

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

The app is written to dist/Transeen.app. Without a Developer ID identity the build is signed ad hoc; set TRANSEEN_SIGNING_IDENTITY for a signed build. The tests are ./scripts/test.sh, ./scripts/test-license.sh and ./scripts/test-lifecycle.sh. The hosted activation service belongs to the official app, so an independent distribution needs its own licensing backend.
