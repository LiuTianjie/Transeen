Transeen/Setup guide

Set up Transeen
in five steps

From the download to your first translated screenshot. You need a Mac with macOS 26 or later and a TR- activation code.

Install

  1. Download the latest DMG from GitHub Releases. It is about 3 MB, one universal app for Apple silicon and Intel.
  2. Open the DMG and drag Transeen to Applications.
  3. Open Transeen from Applications. It lives in the menu bar, so look for its icon there rather than in the Dock.

The app and the DMG are signed with a Developer ID and notarized by Apple, so macOS opens them without a warning. A ZIP and SHA-256 checksums are on the same release page.

Activate

  1. Choose 激活与账号… (Activation and account) in the menu bar menu, or 激活 Transeen in the launcher.
  2. Enter your code, which looks like TR-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX, and choose 激活这台 Mac (Activate this Mac).
  3. If you like, open iTool 账号 (iTool account) and sign in with Google, GitHub or email to bind the license. Signing in to the same account later restores it.

Activation keeps a random installation ID and a receipt in your Keychain; it never reads your Mac’s serial number. One code covers one Mac, and binding an account does not create a second license. StupidMirror SM- and iTool Pro IT- codes are separate products. To get a code, ask in GitHub Discussions.

Allow screen recording

The first time you capture, Transeen asks for the Screen Recording permission. It uses the screen image only, never audio, and only when you press a capture shortcut; it keeps no history and never records continuously.

  1. Choose 打开系统设置… (Open System Settings), or go to System Settings → Privacy & Security → Screen & System Audio Recording.
  2. Find Transeen and turn it on.
  3. Come back to Transeen. It checks again by itself; choose 开始框选 (Start selecting) to carry on.

If it is on but still not working, use 重新检查 (Check again) or 重新打开 (Reopen) in the same window.

Choose languages

The launcher has two menus, 原文 (source) and 译文 (target). Leave the source on 自动识别 (Detect) or choose one of the eight languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, Spanish and German. Any of them translates into any other.

Apple translation needs a language pack for each pair. The guide that opens on first launch, and Settings → 通用 → 翻译 later, list the packs for your target language with their status; 下载 (Download) fetches one before your first capture needs it. After that the translation runs on your Mac, offline. Packs are also listed in System Settings → General → Language & Region → Translation Languages.

Translate a region

  1. Press F1. The screen holds still and dims. On a laptop keyboard that is fn F1, unless the F keys work as standard function keys.
  2. Hover to snap to a paragraph, a field or a window and click, or drag a frame of your own. Esc or a right click cancels.
  3. Same place as last time? Press R while selecting and the last capture’s area is taken again, even after a restart.
  4. Read the translation where the text was. Press Tab to switch to the original and back, or hold Space to peek at it.
  5. Missed a bit? Drag an edge or corner of the capture. It follows the pointer, re-crops from the same frozen screen, keeps your marks in place and translates again when you let go.
  6. Wrong way round? Press F1 again while the capture is open and the two languages swap.

F1 is the only shortcut that works from any app out of the box. To capture for marking up without translating, choose 截图标注 in the menu bar menu, or give it a key in Settings → 快捷键 (Shortcuts); press T in that window if you want the translation after all. To translate a picture you already have, choose 打开图片… (Open image) or press ⌘O.

Mark it up

Choose a tool on the toolbar or press its key: R for a rectangle, O for an ellipse, A for an arrow, P for the pen and V to select and move. Numbered notes count up from 1 and keep their numbers through undo and redo.

Pick one of six colors and three widths, or open the sliders for any color and a width from 1 to 10. ⌘Z and ⌘⇧Z undo and redo; Delete removes the selected mark.

Copy, save or pin

  • ⌘C copies the picture as you see it, marks included, even while a translation is still running. By default this also closes the capture; turn off 复制后关闭截图 in Settings to keep it open.
  • ⌘S saves it as a PNG.
  • The pin (钉到屏幕上) leaves the picture on the screen as a floating window of its own and ends the capture, so the next one can start straight away. Drag a pin anywhere and keep as many as you need; right-click one to copy, save, switch between original and translation or close it, or press Esc while it is focused.
  • 文字 (Text) opens the full translation next to the original, ready to copy.

Use your own model

Apple translation is the default. To use a model, open Settings (⌘,), set 翻译服务 (Translation service) to 大模型 / 本地模型服务 (Model or local model service) and fill in:

  • 接口地址, the full chat completions URL, for example https://api.openai.com/v1/chat/completions;
  • 模型名称, the model name;
  • the API key, if the service needs one, then 保存密钥 (Save key). It is stored in your Keychain.

A server on your own Mac works too. Local addresses may use plain HTTP and need no key, for example http://localhost:11434/v1/chat/completions for Ollama or http://localhost:1234/v1/chat/completions for LM Studio. Remote addresses must use HTTPS.

Model mode sends only the recognized text, never the screenshot. If a request fails, Transeen shows the error and keeps the original picture.

Troubleshooting

Nothing happens when I press F1

On a laptop keyboard F1 changes the brightness unless you hold fn, or turn on “Use F1, F2, etc. keys as standard function keys” in System Settings → Keyboard → Keyboard Shortcuts → Function Keys. Another app may also hold F1; Transeen tells you when it cannot register one. Choose a different key in Settings → 快捷键, or start from 截图翻译 in the menu bar menu.

The capture is empty or the permission keeps asking

Open 屏幕权限… in the menu bar menu. If System Settings already shows Transeen turned on, turn it off and on again, then choose 重新打开 (Reopen).

Apple translation does not start

The language pack for that pair may be missing or still downloading. Download it in Settings → 通用 → 翻译, or check System Settings → General → Language & Region → Translation Languages, and try again.

Some text comes out wrong

Dense layouts, formulas and specialist terms can trip up recognition or translation. Compare with the original (Tab), open 文字 for the full text, or select a smaller region.

Build from source

Transeen is MIT licensed. You need Xcode 26.4 or later, Swift 6 and XcodeGen.

brew install xcodegen
git clone https://github.com/LiuTianjie/Transeen.git
cd Transeen
./scripts/build.sh

The app is written to dist/Transeen.app. Without a Developer ID identity the build is signed ad hoc; set TRANSEEN_SIGNING_IDENTITY for a signed build. The tests are ./scripts/test.sh, ./scripts/test-license.sh and ./scripts/test-lifecycle.sh. The hosted activation service belongs to the official app, so an independent distribution needs its own licensing backend.
