# Transeen 0.2 交互与视觉

用户认为原版仍不好用，苹果/iOS 风格不足。本轮以截图主流程与启动入口为核心，采用 macOS 26 / iOS 26 同系原生 Liquid Glass。

- 主入口直接开始捕获：默认动作、截图标注。设置放进齿轮，不用先读设置表单。
- 截图工具栏分为对照、标注和输出。主要图标按钮 28pt 高；复制有明确主操作样式。
- 对照明确显示原文/译文状态。形状、编号与输出统一放在第一行；选中标注工具后第二行显示颜色、笔触和撤销。自定义值点击调节图标打开浮层。
- 复制后默认结束普通截图；钉住后保留。可在设置关闭复制后收起。
- 提供重新框选。失败信息与普通快捷键提示区分，正在处理时避免重复触发翻译。
- 使用系统 glassEffect / glass 按钮，支持深浅色、减少动态效果和降低透明度。截图本身与原位翻译几何不改变。
- 权限页跟随同一材质与操作层级，不再作为应用主入口。
- 全局快捷键注册与配置仍需实体键盘验证，不把后台按键自动化当成通过。
