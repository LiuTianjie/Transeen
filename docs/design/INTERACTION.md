# 原生、紧凑，也有一点巧思

用户明确要求这是 Mac 工具，控件要符合 macOS，并且「要有意思」。

- 权限页是原生小窗口，系统标题栏、系统按钮、系统字号和语义色，跟随深浅色；去掉大卡片、固定浅色、黑色胶囊主按钮和宣传式大标题。
- 有趣的地方是可操作的取景样例：用外观、通知、键盘快捷键的真实界面样式演示；按住 NSButton 看英文，松开回中文。去掉抽象口号，文字位置固定。授权完成时四角轻收合，遵从减少动态效果设置。
- 权限只在用户主动操作后申请，未授权前保留捕获意图，返回应用时自动检查；成功后由用户点击继续框选。
- 截图工具栏使用系统分段选择器、NSColorWell、原生毛玻璃背景、系统图标和窗口阴影。选中标注工具后显示颜色与线宽。工具名、快捷键都有辅助说明。
- 应用图标采用用户要求的清秀方向：浅米白、灰青色、取景框和 A/文。第一版厚重蓝色玻璃图标已弃用。

没有现场读取到 Codex 自身的权限界面，不声称逐像素复刻。沿用用户要求的交互目标：说明用途、明确下一步、自动识别授权结果、接着做刚才的操作。
